# Контракты, Runtime, модели и layout: проверка документации

[Документация](../docs/efen/README.md) · [Редакционная проверка](DOCUMENTATION-LANGUAGE-REVIEW.md)

Проверка от 2026-11-06. Основание — `main` после обновления до `bb956de`.
Это реорганизация описания языка; выполнение примеров компилятором не проверялось.

## Область поиска

Поиск выполнен по всему `docs/`, включая примеры `.efen`, а также по `dev/`
и корневому README. Проверялись упоминания runtime, рантайма, среды выполнения,
встроенных контрактов, `lang::` и `implementation`, ссылки на переносимые разделы,
объявления `model` и `layout`.

Первичный поиск по Markdown дал 376 совпадений в 58 документах.
После реорганизации повторный поиск охватил 131 файл `docs/`, включая
121 Markdown и примеры. Это тематическое сканирование, а не полная редакционная
проверка каждой статьи или подтверждение реализации описанных механизмов.

кода сохранены на прежнем месте.

## Найденные прежние расхождения

- `runtime/lang-roles.md` относит классы со счётчиком к std и запрещает их без std.
  `memory.md` повторяет это в примечании, но ниже называет реализацией по умолчанию
  `runtime::ArcCounter`; каталог `ArcClass` также допускает реализации из runtime
  и std. Само по себе наличие аспекта в runtime не доказывает независимость от std.
  Нужна отдельная сверка требования зависимости; реорганизация не отменяет его.
- Прежний обзор API содержит конкретные примеры рефлексии, Fiber, барьеров,
  обработчиков и режимов сборки. Они не подтверждены перечнем обязательных
  объявлений; поэтому обзор явно помечен историческим наброском.
- В `memory/viper-proof-model.md` уже была ссылка на отсутствующий фрагмент
  `columnar-layouts.md#доступ-указатели-и-managed`. Она не относится к переносимым
  разделам и не исправлена подбором другого смыслового назначения.

## Проверки

Проверены внутренние файловые ссылки и фрагменты Markdown во всём `docs/`
с сопоставлением с `HEAD`: новых битых ссылок нет, прежняя ошибка указана выше.
Старые точки входа для перенесённых тем контрактов и моделей сохранены.
Блоки кода сбалансированы. `git diff --check` проходит.

Новые статьи и затронутые страницы получили навигационные шапки, перекрёстные
ссылки и футеры. Карты документации, памяти, типов, метапрограммирования и словарь
обновлены.
