## Противоречия

1. Кто отвечает за освобождение параметра-замыкания вида `own`. `types/ownership.md:272-274`: «Обязанность освободить значение остаётся у вызывающего. 2. 4. ## Два способа записать одно

1. Слово `own` в двух смыслах: право (`own T`) и вид замыкания (`() own -> Void`); вместе `own () own -> Void`. `types/ownership.md:274`, `types/function-type.md:78-79`, `closure.md:694-696`.
2. Выходной слот внешней функции: `p: mut T?` или `p: out T` со строкой `ensures written(p) == (…)`. `types/ownership.md:349-351`.
3. Условный отказ от владения: `own T?` с `ensures taken(x)` против `mut Pointer?` (`posix_memalign`). `types/ownership.md:306`, `types/ownership.md:336`.
4. Условный `own fn`: вызов без `take` (`db.sqlite3_close()`) против безусловного `(take x).m()`. `types/ownership.md:358-361`.
5. Источник результата: `-> edit<list> T` у функции, `-> edit T` у метода без `<self>`, но `<self>` в удержании и в `Src: self`. `types/ownership.md:733-736`, `types/access-regions.md:80-83`.
6. Пометка метода: `mut fn`, `mut<self.cache> fn`, `edit self` рядом с частями. `types/access-regions.md:83`, `types/access-regions.md:302`.
7. Право в заголовке `for` словом (`for x in mut v`) и ссылка `&x`/`&read x` в теле; `&x` равно `mut`. `types/ownership.md:548-556`, `types/access-regions.md:105-109`.
8. `immutable`: «свойство слота» (`types/ownership.md:197`), но пишется в типе `immutable Vector<String>` (`types/ownership.md:205`) и «не право» (`types/ownership.md:991`).
9. «Origin»: источник слота (`types/ownership.md:25`), параметр типа `Src: Origin` (`types/ownership.md:470`), путь в скобках (`types/access-regions.md:70`).
10. Слово «область»: три смысла, сказано самим документом (`types/access-regions.md:48`); плюс «ячейка» для слота дескриптора (`types/access-regions.md:1073`).
11. Слот: «переменная, поле или элемент» (`types/ownership.md:21`) и «параметр, локальная переменная, результат вызова, элемент, поле» (`types/access-regions.md:38`).
12. Позиция элемента: `Items.Position<Src>` (`types/access-regions.md:557`, имя «условное», `:564`), `Position<self>` (`types/access-regions.md:537`), `Items.Item`.
13. Держимый источник: `Access<Src> Array<T>` (`types/access-regions.md:622`) и `read<Src> T` (`types/ownership.md:471`).
14. Захват в замыкании: «заимствование» (`closure.md:195`) и «ссылка» (`closure.md:475`); слово «место» остаётся в якорях (`types/ownership.md:468`) и в тексте диагностик (`closure.md:539`, `closure.md:557`).

## Случаи без правила

1. `replace` и ссылка внутрь старого значения; документ не говорит, убивает ли `replace` ссылки (`types/ownership.md:393-400`):
   ```efen
   var s = Item(name: "a")
   let r = &read s.name
   let old = replace(s.name, "b")
   print(r)
   ```
2. Первая запись в `immutable`-слот через `out`; запрещён «аргумент `out`» (`types/ownership.md:219`), но способ первой инициализации `var` без значения не описан:
   ```efen
   var table: immutable Vector<Int>
   fill(into: table)      // fn fill(into: out Vector<Int>)
   ```
3. Результат-структура с источниками из двух параметров (ссылка из двух параметров запрещена, `types/ownership.md:728`, но удержание допускает несколько путей, `types/access-regions.md:82`):
   ```efen
   fn zip(a: Vector<Int>, b: Vector<Int>) -> ZipIter<read Int, Src: a, b>
   ```
4. Функция с путём в источнике, положенная в тип функции (в типе путь запрещён, `types/function-type.md:217`):
   ```efen
   fn title(doc: Document) -> read<doc.title> String
   let f: (doc: Document) -> read<doc> String = title
   ```
5. Держатель-курсор после обычного `take` источника (`types/ownership.md:424-429` описывает только «событие, которому нужен свободный слот»):
   ```efen
   let c = items.reading()
   let moved = take items
   c.next()
   ```
6. Ссылка внутри ссылки: `&x.field`, где `x` уже ссылка (`types/ownership.md:537` против `:873`):
   ```efen
   let x = &v[0]
   let y = &x.name
   ```
7. `own fn` через ссылку (`types/ownership.md:361` говорит только о слоте и `(take x).m()`):
   ```efen
   let r = &doc
   (take r).close()
   ```
8. Срез из вызова с `mut`-источником и второй срез того же источника, затем смена структуры через один из них (`types/ownership.md:939-941` говорит о срезах без права `mut`):
   ```efen
   let a = headMut(values: nums, n: 2)    // -> mut<values> [Int]
   let b = headMut(values: nums, n: 3)
   a.append(1)
   print(b[0])
   ```
9. `Position<self>` после `remove` на другом курсоре-номере: «могут указывать на сдвинутые элементы; выход за границу ловит проверка номера» (`types/access-regions.md:538-539`), но что с номером внутри границ, не сказано:
   ```efen
   let c1 = items.start(); let c2 = items.start()
   items.remove(at: c1)
   items.peek(at: c2)
   ```
10. Захват результата-ссылки замыканием, переданным в метод, который вызывает его и сохраняет одновременно (`closure.md:581-585` делит только на «не сохраняют» и «сохраняют»):
   ```efen
   bus.fireAndKeep(() -> Void { shape.hp = 0 })   // shape — ссылка из find
   ```
