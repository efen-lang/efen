# Оператор `is`

`is` — это оператор сопоставления с образцом (pattern matching) в языке `Efen`, 
предназначенный для проверки, соответствует ли значение заданному образцу. 
Он позволяет выполнять мощное и выразительное сопоставление вне конструкции `match`, 
делая код чище и компактнее.

## Базовый синтаксис

```efen
<выражение> is <образец>
```

Оператор возвращает `true`, если значение соответствует образцу, и `false` в противном случае. 
Поддерживаются все те же образцы, что и в `match`.

## Поддержка интерфейсов и типов

Оператор `is` может использоваться для проверки:
- Является ли значение объектом класса, реализующего определённый интерфейс.
- Является ли значение экземпляром класса определённого типа **в runtime**, 
  если тип поддерживает соответствующий контракт сопоставления 
  (контракт `matchable`).

Пример:
```efen
if obj is MyInterface {
    obj.doWork()
}

if obj is MyClass {
    // Приведение и использование
}
```

## Примеры использования

### Проверка на константу
```efen
if number is 0 {
    print("Ноль")
}
```

### Диапазон
```efen
if number is 1..<10 {
    print("Малое число")
}
```

### Несколько образцов через `|`
```efen
if char is "a" | "e" | "i" | "o" | "u" {
    print("Гласная")
}
```

Знак `|` принадлежит образцу и перечисляет его альтернативы. Запятая в образцах
не используется.

### Объединение условий

Справа от `is` стоит один образец, поэтому два условия соединяются оператором `||`:

```efen
if char is "a" | "e" || isDigit(char) {
    print("Гласная или цифра")
}
```

Оператор `is` неассоциативен: два `is` подряд без скобок — ошибка компиляции.

```efen
a is B is C      // ошибка компиляции
(a is B) is C    // допустимо
```

### Кортежи
```efen
let point = (1, 0)
if point is (let x, 0) {
    print("На оси X, x = ${x}")
}
```

### Условия с where
```efen
if point is (let x, let y) where x == y {
    print("На диагонали y = x")
}
```

### Optional
```efen
if value is let n? {
    print("Есть значение: ${n}")
} else if value is null {
    print("Значение отсутствует")
}
```

### Enum
```efen
enum Status {
    success
    error { message: String }
}

let s = Status.error(message: "Ошибка сети")

if s is .error.{ let message } {
    print("Ошибка: ${message}")
}
```

Поля варианта перечисляет [оператор проекции `.{ }`](types/projection.md);
связывает только `let`. Справа от `is` запись `Type.{ … }` — всегда образец, а не
проекционный тип: она связывает копии значений полей и представления не создаёт.

## Использование в выражениях

```efen
let size = if n is 0 {
    "Ноль"
} else if n is 1..<10 {
    "Мало"
} else {
    "Много"
}
```

## Связывание и сравнение

Связывает только `let`. Голое имя в образце ничего не объявляет — оно
сравнивается со значением, которое это имя уже имеет.

```efen
let expected = 404

if code is expected {              // сравнение с переменной expected
    print("Ожидаемый код")
}

if point is (let x, 0) {           // связывание: x — новое имя
    print(x)
}
```

`let` стоит либо перед одним именем, либо перед составным образцом
(`let (x, y)`) — тогда связываются все голые имена внутри него.

## Поведение переменных

Переменные, извлечённые через `let`, доступны только внутри блока, где сработало сопоставление. 
Это безопасно и предотвращает утечки значений.

## Рекомендации по использованию

1. Используйте `is`, если нужно проверить только один образец.
2. Используйте `match`, если нужно обработать несколько образцов исчерпывающе.
3. Не забывайте про `where`, если нужны дополнительные условия.
4. Для привязки значений используйте `let` прямо внутри образца: голое имя сравнивает, а не связывает.
5. Используйте `|` для перечисления альтернатив внутри одного образца.
