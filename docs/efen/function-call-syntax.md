# Синтаксис вызова функций

Этот документ описывает вызовы. В объявлении функции без параметров пустые
скобки запрещены: `fn reset { ... }`. При вызове они обязательны: `reset()`.
Причина различия описана в [философии языка](philosophy.md#один-канонический-способ).

В Efen функцию можно вызвать со скобками или передать ей один аргумент без скобок.

## Обычный вызов

Круглые скобки — универсальная форма вызова. Она обязательна для вызова без
аргументов и для передачи нескольких аргументов:

```efen
doSomething()
add(5, 3)
greet("John", "Doe")

// пробел перед `(` не превращает аргументы в tuple
add (5, 3)

// один tuple-аргумент обозначается дополнительной парой скобок
add((5, 3))

calculate(multiply(2, 3), add(4, 5))
```

Пробел между вызываемым выражением и `(` не меняет обычный вызов:
`add (x, y)` передаёт два аргумента и равнозначен `add(x, y)`. Пробельная форма
с одним аргументом не принимает tuple-литерал; один аргумент `(x, y)` пишется
только как `add((x, y))`.

Именованные и обобщённые параметры также используют обычную форму:

```efen
greet(firstName: "John", lastName: "Doe")
identity<Int>(42)
```

## Вызов с одним аргументом через пробел

Пробел между вызываемым выражением и аргументом означает вызов функции с одним
аргументом:

```efen
echo x
println "Hello, World!"
save document
```

Эти выражения эквивалентны по смыслу, каноническая форма выбирается правилами
стиля (см. «Выбор формы вызова»):

```efen
echo x
echo(x)
```

Аргументом является всё следующее выражение, поэтому скобки вокруг составного
аргумента не нужны:

```efen
echo x + 1                    // echo(x + 1)
log "Result: " + result      // log("Result: " + result)
assert count > 0              // assert(count > 0)
echo user.name ?? "unknown"  // echo(user.name ?? "unknown")
```

### Где допустим пробельный вызов

Пробельный вызов стоит в начале инструкции либо после знака: `=`, оператора,
открывающей круглой скобки, запятой. После ключевого слова он запрещён, и
вызываемое выражение не может стоять сразу после другого идентификатора.

```efen
echo x                 // начало инструкции
let value = f y        // после `=`
let total = a + f y    // после оператора
process(f y)           // после `(`
call(a, f y)           // после запятой

return f y             // ошибка компиляции: после ключевого слова
if f y { }             // ошибка компиляции: после ключевого слова
throw make x           // ошибка компиляции: после ключевого слова
save load path         // ошибка компиляции: вызов сразу после идентификатора
```

Правило не смотрит на типы и на сигнатуры: место вызова определяется тем, что
стоит слева от него.

### Аргумент на той же строке

Аргумент пробельного вызова начинается на строке вызываемого выражения. Перевод
строки перед ним завершает инструкцию, так же как перевод строки перед `(` или
`[` не продолжает вызов и индексацию:

```efen
print
value              // две инструкции: print и value

let task = makeTask()
(take task)()      // две инструкции
```

Общие правила — [перенос строк](operators.md#перенос-строк).

### Ровно один аргумент

Запятая не продолжает вызов без скобок. Несколько аргументов всегда требуют
обычной формы вызова:

```efen
add x, y              // ошибка компиляции
printf "format", value // ошибка компиляции

add(x, y)               // допустимо
printf("format", value) // допустимо
```

### Цепочки пробельных вызовов запрещены

Цепочка запрещена тем же правилом: во втором применении вызов стоит после
идентификатора. Компилятор не группирует последовательность пробельных применений
ни слева, ни справа, поэтому такие выражения являются ошибкой независимо от
сигнатур функций:

```efen
save load path        // ошибка компиляции
echo format value     // ошибка компиляции
some calculate x      // ошибка компиляции
```

Вложенный вызов необходимо обозначить скобками:

```efen
save load(path)       // save(load(path))
save(load(path))      // то же самое
echo format(value)    // echo(format(value))
```

Таким образом, синтаксический разбор не зависит от типов, количества параметров
или доступных перегрузок.

### Выбор формы вызова

Грамматика везде одна: аргумент пробельного вызова — всё следующее выражение.
Каноническую форму выбирают правила стиля:

- в начале инструкции канонична запись через пробел, аргумент может быть любым
  выражением: `echo x + 5` означает `echo(x + 5)`;
- в остальных допустимых местах — после `=`, оператора, `(`, запятой — через
  пробел пишется только простой аргумент: имя, литерал, цепочка членов. Аргумент
  с оператором верхнего уровня или `=>` пишется через `<|`;
- скобки `f(x)` для одного аргумента пишутся только там, где пробельный вызов
  запрещён: после ключевого слова и после идентификатора.

```efen
echo x + 5               // канонично
log items.map => item * 2  // log(items.map => item * 2)
let v = f y              // простой аргумент
let x = fun <| x + 5     // большой аргумент не в начале инструкции
return f(y)              // после ключевого слова

echo <| x + 5            // S: в начале инструкции канонична запись через пробел
echo(x)                  // S: пробельный вызов здесь допустим
let x = fun x + 5        // S: fun(x + 5), каноническая запись fun <| x + 5
```

## Явное применение `<|`

`<|` явно отделяет вызываемое выражение от единственного аргумента. По смыслу
это тот же вызов, что и через пробел:

```efen
echo <| x
echo x
echo(x)
```

Явную форму пишут для большого аргумента вне начала инструкции (см. выбор формы
вызова выше):

```efen
let page = render <| if ready { page } else { fallback }
let total = sum <| a + b
```

`<|` принимает ровно одно выражение. Запятая после аргумента не добавляет
параметры:

```efen
printf <| "format", value  // ошибка компиляции
printf("format", value)    // допустимо
```

В отличие от пробела, явный `<|` можно использовать в цепочке. Цепочка
правоассоциативна, поэтому границы каждого вызова однозначны:

```efen
save <| load <| path
// save(load(path))

print <| format <| calculate <| value
// print(format(calculate(value)))

save <| load path
// ошибка компиляции: внутренний вызов через пробел образует запрещённую цепочку
```

## Методы и замыкания

Те же правила применяются к методам и функциям высшего порядка:

```efen
user.getName()
list.add item
numbers.map => item * 2

process user.getName()
let names = users.map => user.name
```

Единственный аргумент-замыкание передаётся хвостом через `=>`. Замыкание среди
нескольких аргументов пишется в скобках вместе с ними; хвост после списка
аргументов недопустим:

```efen
numbers.reduce(0, (acc, x) => acc + x)
numbers.reduce(0) => left + right                // недопустимо

let names = users.map((u) => u.name)        // S: каноническая форма — хвостовая
let names = users.map <| (u) => u.name      // S: каноническая форма — хвостовая
```

## Сводка

| Форма | Назначение | Пример |
|---|---|---|
| `f()` | Вызов без аргументов | `getValue()` |
| `f(arg)` | Один аргумент там, где пробел запрещён | `return f(y)` |
| `f(a, b)` | Вызов с несколькими аргументами | `add(1, 2)` |
| `f expression` | Вызов с одним аргументом-выражением | `echo x + 1` |
| `f <| expression` | Большой аргумент вне начала инструкции | `let t = sum <| a + b` |
| `f => closure` | Единственный аргумент-замыкание | `numbers.map => item * 2` |

Ключевые ограничения:

- пробельный вызов стоит в начале инструкции или после знака;
- после ключевого слова и после идентификатора пробельный вызов запрещён;
- вызов без скобок принимает ровно один аргумент;
- хвостовое замыкание `=>` допустимо только как единственный аргумент;
- аргумент продолжается до конца текущего выражения;
- аргумент, `(` и `[` на следующей строке начинают новую инструкцию;
- запятая без скобок является ошибкой;
- цепочки пробельных применений являются ошибкой;
- цепочки `<|` разрешены и группируются справа;
- вложенные вызовы обозначаются круглыми скобками или явной цепочкой `<|`.
