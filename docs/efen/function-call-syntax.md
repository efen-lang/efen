# Синтаксис вызова функций

В Efen функцию можно вызвать со скобками или передать ей один аргумент без скобок.

## Обычный вызов

Круглые скобки — универсальная форма вызова. Она обязательна для вызова без
аргументов и для передачи нескольких аргументов:

```efen
doSomething()
println("Hello")
add(5, 3)
greet("John", "Doe")

calculate(multiply(2, 3), add(4, 5))
```

Именованные и generic-параметры также используют обычную форму:

```efen
greet(firstName: "John", lastName: "Doe")
identity<Int>(42)
```

## Вызов с одним аргументом через пробел

Пробел между вызываемым выражением и аргументом означает вызов функции с одним
аргументом:

```efen
echo x
println "Hello, World!"
save document
```

Эти выражения эквивалентны:

```efen
echo x
echo(x)
```

Аргументом является всё следующее выражение, поэтому скобки вокруг составного
аргумента не нужны:

```efen
echo x + 1                    // echo(x + 1)
log "Result: " + result      // log("Result: " + result)
assert count > 0              // assert(count > 0)
echo user.name ?? "unknown"  // echo(user.name ?? "unknown")
```

### Где допустим пробельный вызов

Пробельный вызов стоит в начале инструкции либо после знака: `=`, оператора,
открывающей круглой скобки, запятой. После ключевого слова он запрещён, и
вызываемое выражение не может стоять сразу после другого идентификатора.

```efen
echo x                 // начало инструкции
let value = f y        // после `=`
let total = a + f y    // после оператора
process(f y)           // после `(`
call(a, f y)           // после запятой

return f y             // ошибка компиляции: после ключевого слова
if f y { }             // ошибка компиляции: после ключевого слова
throw make x           // ошибка компиляции: после ключевого слова
save load path         // ошибка компиляции: вызов сразу после идентификатора
```

Правило не смотрит на типы и на сигнатуры: место вызова определяется тем, что
стоит слева от него.

### Ровно один аргумент

Запятая не продолжает вызов без скобок. Несколько аргументов всегда требуют
обычной формы вызова:

```efen
add x, y              // ошибка компиляции
printf "format", value // ошибка компиляции

add(x, y)               // допустимо
printf("format", value) // допустимо
```

### Цепочки пробельных вызовов запрещены

Цепочка запрещена тем же правилом: во втором применении вызов стоит после
идентификатора. Компилятор не группирует последовательность пробельных применений
ни слева, ни справа, поэтому такие выражения являются ошибкой независимо от
сигнатур функций:

```efen
save load path        // ошибка компиляции
echo format value     // ошибка компиляции
some calculate x      // ошибка компиляции
```

Вложенный вызов необходимо обозначить скобками:

```efen
save load(path)       // save(load(path))
save(load(path))      // то же самое
echo format(value)    // echo(format(value))
```

Таким образом, синтаксический разбор не зависит от типов, количества параметров
или доступных перегрузок.

## Явное применение `<|`

`<|` явно отделяет вызываемое выражение от единственного аргумента. По смыслу
это тот же вызов, что и через пробел:

```efen
echo <| x
echo x
echo(x)
```

Явную форму используют, когда один пробел плохо показывает границу вызова или
начало аргумента визуально похоже на оператор:

```efen
echo <| -x
callback <| value
render <| if ready { page } else { fallback }
```

`<|` принимает ровно одно выражение. Запятая после аргумента не добавляет
параметры:

```efen
printf <| "format", value  // ошибка компиляции
printf("format", value)    // допустимо
```

В отличие от пробела, явный `<|` можно использовать в цепочке. Цепочка
правоассоциативна, поэтому границы каждого вызова однозначны:

```efen
save <| load <| path
// save(load(path))

print <| format <| calculate <| value
// print(format(calculate(value)))

save <| load path
// ошибка компиляции: внутренний вызов через пробел образует запрещённую цепочку
```

## Методы и замыкания

Те же правила применяются к методам и функциям высшего порядка:

```efen
user.getName()
list.add(item)
numbers.map((x) => x * 2)

process user.getName()
numbers.map <| (x) => x * 2
```

## Сводка

| Форма | Назначение | Пример |
|---|---|---|
| `func()` | Вызов без аргументов | `getValue()` |
| `func(arg)` | Обычный вызов | `print(value)` |
| `func(a, b)` | Вызов с несколькими аргументами | `add(1, 2)` |
| `func expression` | Вызов с одним аргументом-выражением | `echo x + 1` |
| `func <| expression` | Явно отделённый единственный аргумент | `echo <| -x` |

Ключевые ограничения:

- пробельный вызов стоит в начале инструкции или после знака;
- после ключевого слова и после идентификатора пробельный вызов запрещён;
- вызов без скобок принимает ровно один аргумент;
- аргумент продолжается до конца текущего выражения;
- запятая без скобок является ошибкой;
- цепочки пробельных применений являются ошибкой;
- цепочки `<|` разрешены и группируются справа;
- вложенные вызовы обозначаются круглыми скобками или явной цепочкой `<|`.
