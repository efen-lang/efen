# Операторы и приоритеты

В `Efen` определен широкий набор операторов, от стандартных арифметических до специфичных для функционального программирования. Порядок выполнения операций определяется их приоритетом (precedence) и ассоциативностью.

## Таблица приоритетов

Операторы перечислены в порядке убывания приоритета (сверху вниз). Операторы в одной группе имеют одинаковый приоритет.

| Группа | Операторы | Ассоциативность | Описание |
|:---:|:---:|:---:|---|
| **Первичные** | `()` `[]` `{}` | — | Группировка, Литералы массивов/словарей/блоков |
| | `.` `?.` | Слева | Доступ к членам, Optional chaining |
| | `()` `?()` | Слева | Вызов функции, Optional call |
| | `[]` `?[]` | Слева | Индексация (Subscript), Optional subscript |
| **Постфиксные** | `++` `--` | — | Постфиксный инкремент/декремент |
| **Префиксные** | `++` `--` | — | Префиксный инкремент/декремент |
| | `+` `-` | — | Унарный плюс и минус |
| | `!` `~` | — | Логическое НЕ, Побитовое НЕ |
| **Типы** | `as` `as?` | Слева | Приведение типов |
| | `is` | Слева | Проверка типа |
| **Мультипликативные** | `*` `/` `%` | Слева | Умножение, Деление, Остаток |
| **Аддитивные** | `+` `-` | Слева | Сложение, Вычитание |
| **Сдвиги** | `<<` `>>` | Слева | Побитовые сдвиги |
| **Побитовые** | `&` | Слева | Побитовое И |
| | `^` | Слева | Побитовое Исключающее ИЛИ |
| | `|` | Слева | Побитовое ИЛИ |
| **Диапазоны** | `..` `..<` `<..` `<..<` | — | Создание диапазонов |
| **Сравнение** | `==` `!=` | Слева | Равенство |
| | `<` `>` `<=` `>=` | Слева | Сравнение величин |
| | `<=>` | Слева | Spaceship (трехстороннее сравнение) |
| **Логические** | `&&` | Слева | Логическое И |
| | `||` | Слева | Логическое ИЛИ |
| **Null-safety** | `??` | Слева | Null Coalescing |
| | `?:` | Слева | Elvis оператор |
| **Тернарный** | `? :` | Справа | Условный оператор |
| **Пары** | `:` | Справа | Пары ключ-значение |
| **Присваивание** | `=` | Справа | Присваивание |
| | `+=` `-=` `*=` `/=` `%=` | Справа | Составное присваивание |
| **Функциональные** | `<|` | Справа | Явное применение функции к одному аргументу |
| **Замыкания** | `=>` | Справа | Arrow syntax |

## Детальное описание

### Арифметические операторы

Стандартный набор математических операций.

```efen
let a = 10 + 5   // 15
let b = 10 - 5   // 5
let c = 10 * 5   // 50
let d = 10 / 5   // 2
let e = 10 % 3   // 1
```

Также поддерживаются унарные префиксы и инкременты:

```efen
let x = -5
var y = 10
y++ // y станет 11
```

### Операторы сравнения

Возвращают `Bool`.

```efen
if a == b { ... }
if a != b { ... }
if a >= 10 { ... }

let cmp1 = 10 <=> 20 // -1
let cmp2 = 20 <=> 20 // 0
let cmp3 = 30 <=> 20 // 1
```

### Логические и побитовые операторы

```efen
if isValid && !isEmpty { ... }
if hasError || isWarning { ... }

let mask = 0b1010
let and = mask & 0b1100
let or  = mask | 0b0001
let xor = mask ^ 0b1111
let not = ~mask
let shift = 1 << 3
```

### Null-safety

```efen
let city = user?.address?.city
callback?("event")
let item = array?[index]
let name = optionalName ?? "Guest"
let val = input ?: default
```

### Диапазоны

```efen
1..5
1..<5
1<..5
1<..<5
```

### Типы

```efen
if obj is String { ... }

let s = obj as String
let s2 = obj as? String
```

### Функциональные операторы

#### `<|`

```efen
log <| "Error: " + msg
save <| load(path)
```

`<|` явно отделяет функцию от единственного аргумента и по смыслу эквивалентен
вызову через пробел или скобки:

```efen
echo <| x
echo x
echo(x)
```

Явные цепочки `<|` разрешены и группируются справа. Пробельные цепочки при этом
запрещены компилятором:

```efen
save <| load path        // ошибка компиляции
save <| load <| path     // save(load(path))
save <| load(path)       // save(load(path))
```

#### `=>`

```efen
let double = (x) => x * 2
numbers.map => $0 * 2
```

## Ассоциативность

**Левая:**

`a - b - c` = `(a - b) - c`

**Правая:**

`a = b = c` = `a = (b = c)`

```efen
f <| g <| x
// f(g(x))
```
