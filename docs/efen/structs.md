# Структуры

[Документация](README.md) · [Контракты](contracts.md) · [Runtime языка Efen](runtime/README.md) · [Память](memory/README.md)

Структура объявляет набор полей и способ объединить их в одно значение.
В её теле хранятся данные; методы и другое поведение предоставляются
стратегиями. Структура может содержать другие структуры, в том числе
встраивать их поля.

Само объявление `struct` не обещает малый размер или дешёвое копирование.
Возможность копировать и перемещать значение задаётся отдельными контрактами.

## Базовый синтаксис

Структура объявляется с помощью ключевого слова `struct`:

```efen
struct Point {
    var x: Int
    var y: Int
}

// Создание экземпляра
let point = Point(x: 10, y: 20)
```

## Поля структур

Структуры могут содержать изменяемые (`var`) и неизменяемые (`let`) поля.

Поле владеет своим значением. Два поля указывают в одну память, только если это объявлено правом с источником или
`layout`
([поля не делят память](types/ownership.md#поля-не-делят-память)).

```efen
struct Rectangle {
    let width: Int
    let height: Int
    var color: String = "black"
}

// Использование
var rect = Rectangle(width: 100, height: 50)
// rect.width = 200  // Ошибка: width неизменяемое
rect.color = "red"   // поле var и доступное право записи разрешают изменение
```

`let` запрещает перепривязать саму переменную. Запись в поле `var` разрешена,
если тип допускает изменение и связывание располагает правом записи: `edit`, если прежнее значение поля ничем не владеет, иначе `mut`.

```efen
let bound = Rectangle(width: 100, height: 50)
bound.color = "red"
```

<a id="поля-с-значениями-по-умолчанию"></a>

### Поля со значениями по умолчанию

```efen
struct Configuration {
    var host: String = "localhost"
    var port: Int = 8080
    var timeout: Int = 30
}

// Можно создать со значениями по умолчанию
let config1 = Configuration()

// Или переопределить нужные
let config2 = Configuration(port: 3000)
```

## Композиция структур

Efen поддерживает встраивание одной структуры в другую через указание имени типа.

### Встроенные типы

```efen
struct Position {
    var x: Int
    var y: Int
}

struct Entity {
    var name: String
    Position  // Встраивание Position
}

// При использовании поля Position становятся доступны напрямую
let entity = Entity(
    name: "Player",
    x: 100,
    y: 200
)

echo entity.x      // 100
echo entity.name   // "Player"
```

### Множественная композиция

```efen
struct Velocity {
    var dx: Int
    var dy: Int
}

struct Sprite {
    var texture: String
}

struct MovingSprite {
    Velocity
    Sprite
    var rotation: Float = 0.0
}

let sprite = MovingSprite(
    dx: 5,
    dy: 3,
    texture: "hero.png",
    rotation: 45.0
)
```

<a id="паттерн-mixin-через-композицию"></a>

### Повторное использование групп полей

```efen
struct Timestamped {
    var createdAt: Int
    var updatedAt: Int
}

struct Identifiable {
    var id: String
}

struct User {
    Timestamped
    Identifiable
    var name: String
    var email: String
}

let user = User(
    id: "user123",
    name: "Alice",
    email: "alice@example.com",
    createdAt: 1234567890,
    updatedAt: 1234567890
)
```

<a id="дженерик-структуры"></a>

## Структуры с параметрами типов

Структуры поддерживают параметры типа.

```efen
struct Box<T> {
    var value: T
}

let intBox = Box<Int>(value: 42)
let stringBox = Box<String>(value: "hello")
```

<a id="композиция-с-дженериками"></a>

### Встраивание параметризованного типа

```efen
struct RefCounted<T> {
    var refCount: Int = 0
    T  // Встраивание дженерик-типа
}

struct Data {
    var bytes: [Byte]
}

// RefCounted<Data> будет иметь поля: refCount и bytes
let data = RefCounted<Data>(
    refCount: 1,
    bytes: [0x01, 0x02, 0x03]
)
```

<a id="ограничения-дженерик-типов"></a>

### Ограничения параметров типов

```efen
struct Wrapper<T: Comparable> {
    var value: T
}

strategy WrapperComparison<T> for Wrapper<T> {
    fn isGreaterThan(other: Wrapper<T>) -> Bool {
        return value > other.value
    }
}
```

Структуры содержат только данные. Методы и другое поведение предоставляются
стратегиями; их функции не становятся физическими полями структуры. Внешний
пакет может применить стратегию к структуре только при её `allow strategies`.

## Семантика значений

Структуры являются типами-значениями, но это само по себе не разрешает
копирование. Явную копию даёт соответствие `Copyable`, а перенос существующего значения даёт независимый контракт
`Movable`. Неявно структура не копируется: строку `conforms ImplicitlyCopyable` пишут только модули языка, и в
пользовательской структуре она вызывает ошибку. Связывание `var b = a` даёт второе имя того же значения
([связывание существующего значения](types/ownership.md#связывание-существующего-значения)), а копию даёт только
`copy`.

```efen
struct Point {
    conforms Copyable

    var x: Int
    var y: Int
}

var p1 = Point(x: 10, y: 20)
var p2 = copy p1  // копия: только словом copy

p2.x = 30

echo p1.x  // 10: оригинал не изменился
echo p2.x  // 30

var p3 = p1       // второе имя значения p1, не копия
p3.x = 40
echo p1.x  // 40: запись через второе имя пишет в p1
```

<a id="copy-on-write-оптимизация"></a>

### Копирование при записи

При копировании с отложенным отделением данных (CoW) два значения сначала
могут использовать общее физическое хранилище. Перед изменением тип создаёт
независимые данные для изменяемой копии. Способ хранения и отделения должен
обеспечивать реализация типа; объявление `struct` само по себе его не включает.

У типов модулей языка с `ImplicitlyCopyable` неявная копия не выделяет память и
не меняет наблюдаемое поведение программы. Изменение скрытого счётчика ссылок
допустимо. Операция записи, при которой копия отделяется, рассматривается
отдельно. Явный `copy` создаёт независимые данные по правилам `Copyable`.
Подробнее — [контракты копирования](runtime/value-operations.md#контракты-копирования-и-перемещения).

## Отличия от классов

Структура — примитив ниже класса: у класса есть конструктор и деструктор, у структуры их нет. Структуру создаёт
вызов `T(…)`, который только записывает поля, а память, которой она владеет, освобождает явный код. Компилятор не
вставляет за программиста ни инициализации, ни очистки: выход из области со структурой, у которой владеющее поле
может быть непустым, — ошибка компиляции
([уничтожение структуры из `layout`](memory/layout-reference.md#74-ничего-не-теряется)).

| Аспект | Структура | Класс |
|--------|-----------|-------|
| Семантика | Тип-значение | Один владелец; общий объект — `conforms ArcClass` ([классы](classes.md#управление-памятью)) |
| Копирование | По `Copyable`, только явным `copy`; `ImplicitlyCopyable` объявляют только модули языка | По тем же контрактам |
| Наследование | По началу: встраивание первым полем ([сырая память](memory/pointer.md)) | Да |
| Композиция | Встраивание и обычные поля | Обычные поля; наследование — отдельный механизм |
| Инициализация | Вызов `T(…)` записывает поля; конструктора нет | Вызов `T(…)`, конструктор `@constructor fn init` при `conforms Constructible` |
| Уничтожение | Деструктора нет: память, которой структура владеет, освобождает явный код | Деструктор `@destructor fn deinit` ([деструкторы](disposable.md)) |
| Методы | Своих нет; стратегия даёт функции извне, которые вызываются как методы ([стратегии](strategies.md)) | Да: методы класса |
| Размер и хранение | Определяются конкретным типом и его представлением | Также определяются типом; наследование и служебные поля зависят от подключённых возможностей |

Встраивание общей структуры не создаёт иерархию классов:

```efen
struct Function {
    BaseNode
    var body: HirNodeId
}
```

У `Function` не появляется таблица виртуальных методов. Встраивание первым полем — наследование по началу:
память `Function` начинается с памяти `BaseNode`, поэтому приведение `as` между ними в
`layout` доказывается устройством структур ([сырая память](memory/pointer.md)). Голое имя
типа физически встраивает его в объявленную позицию: поскольку `BaseNode` стоит
первым, обычное значение `Function` начинается со структуры `BaseNode`.
Выражение `function.BaseNode` обозначает встроенный слот целиком.

При колоночном хранении проекция хранилища может размещать логические
компоненты отдельно. В этом случае целое значение `Function` ещё не собрано
в обычную последовательность полей. Если оно требуется, представление должно
собрать его с тем же порядком встроенных компонентов.

### Когда использовать структуры

Структуры удобны для явного описания данных: координат, параметров
конфигурации, записей протокола и узлов внутренних представлений компилятора.
Размер и сложность данных сами по себе не запрещают использование структуры.

Если данным нужны операции, их можно предоставить стратегией. Если требуется
объединить методы с состоянием, использовать наследование классов или
подключить стандартный подсчёт владельцев через `ArcClass`, рассмотрите
[класс](classes.md).

## Декораторы

Структуры поддерживают декораторы на уровне объявления и полей.

```efen
@serializable
@packed
struct NetworkPacket {
    @bigEndian
    var header: Int32

    @compressed
    var payload: [Byte]

    var checksum: Int32
}
```

### Декораторы для генерации кода

```efen
@equatable
@hashable
struct Person {
    var name: String
    var age: Int
}

// Декораторы автоматически генерируют:
// - fn equals(other: Person) -> Bool
// - fn hash -> Int
```

## Вложенные структуры

```efen
struct Outer {
    struct Inner {
        var value: Int
    }

    var data: Inner
}

// Использование
let outer = Outer(
    data: Outer.Inner(value: 42)
)
```

## Работа с памятью

### Размер и выравнивание

```efen
struct Compact {
    var a: Byte   // 1 байт
    var b: Byte   // 1 байт
    var c: Int16  // 2 байта
}  // Размер: 4 байта с выравниванием

@packed
struct Packed {
    var a: Byte
    var b: Byte
    var c: Int16
}  // Размер: 4 байта без промежутков для выравнивания
```

## Примеры использования

### Структура для 2D графики

```efen
struct Vector2D {
    var x: Float
    var y: Float
}

struct Transform2D {
    Vector2D    // position
    var rotation: Float = 0.0
    var scale: Float = 1.0
}

let transform = Transform2D(
    x: 100.0,
    y: 200.0,
    rotation: 45.0
)
```

### Структура для конфигурации

```efen
struct DatabaseConfig {
    var host: String = "localhost"
    var port: Int = 5432
    var username: String
    var password: String
    var maxConnections: Int = 10

let config = DatabaseConfig(

```

```efen
struct Article {
    Timestamped

    var content: String
    var author: String

```

## Лучшие практики

1. **Держите структуры простыми**: Используйте для данных, а не для поведения
2. **Используйте композицию**: Встраивайте другие структуры вместо дублирования полей
3. **Значения по умолчанию**: Предоставляйте подходящие значения по умолчанию для необязательных полей
4. **Неизменяемость**: Предпочитайте `let` вместо `var`, где возможно
5. **Документируйте**: Поясняйте назначение структуры и её полей

```efen
/// Представляет точку в 2D пространстве
struct Point {
    /// X координата
    var x: Int

    /// Y координата
    var y: Int
}
```
