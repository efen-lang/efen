# Функции

## Определение функций

`Efen` поддерживает определение функций с помощью ключевого слова `fn`. 
Вот пример простой функции, которая принимает два аргумента и возвращает их сумму:

```efen
fn add(a: Int, b: Int) -> Int {
    return a + b
}
```

Функции могут быть определены на уровне модуля, внутри классов или интерфейсов.
Функции могут иметь параметры с типами, а также возвращаемый тип. Тип результата
из тела обычной функции не выводится. Если `-> Type` отсутствует, результатом
является `Void`, и `return expression` в таком теле является ошибкой:

```efen
fn answer {
    return 42 // ошибка: объявите `-> Int`
}

fn answer -> Int {
    return 42
}
```

Готовая сигнатура может быть получена из явно указанного прототипа, contract или
interface; это не является выводом результата из тела.

### Функции без параметров

Объявление функции без параметров записывается без пустого списка `()`:

```efen
fn reset {
    // ...
}

fn count -> Size {
    return items.count
}
```

Пустые скобки в объявлении являются синтаксической ошибкой:

```efen
fn reset() { } // Ошибка: удалите `()`.
```

Это применение принципа [уменьшения разнообразия синтаксиса](philosophy.md):
две формы не несут разной семантики, поэтому язык оставляет одну. Правило
действует для функций модулей, методов, статических функций, метафункций,
объявлений в контрактах и интерфейсах, а также конструкторов без параметров.

Вызов функции по-прежнему использует скобки — `reset()`. Он синтаксически
отличается от получения функции `reset` как значения.

## Функция из прототипа

Функции могут быть определены на основе сигнатуры (прототипа) функции. Например:
```efen
alias Adder = (a: Int, b: Int) -> Int

fn add: Adder {
    return a + b
}
```

## Функция и атрибуты функций

Атрибуты функций определяются разработчиком
и доступны как префиксы к определению функции.

```efen
public fn publicFunction {
    // Доступна из других модулей и пакетов
}
internal fn internalFunction {
    // Доступна только внутри текущего пакета
}
private fn privateFunction {
    // Доступна только внутри текущего модуля
}
api fn apiFunction {
    // `api` разворачивается по составному атрибуту главного модуля пакета
}
```

## Дженерик-функции

`Efen` поддерживает параметры типа (generics) для функций, позволяя создавать универсальные алгоритмы:

```efen
fn identity -> T {
    generic T: Type
    param value: T

    return value
}

let num = identity<Int>(42)
let str = identity<String>("hello")
```

Дженерик функция с прототипом:

```efen
alias Wrapper<T> = (value: T) -> T
fn wrap: Wrapper<T> {
    generic T: Type
    return value
}
```

### Множественные параметры типа

Функции могут иметь несколько параметров типа:

```efen
fn map -> [U] {
    generic T: Type
    generic U: Type
    param items: [T]
    param transform: (T) -> U

    return items.map => transform($item)
}

let numbers = [1, 2, 3]
let strings = map(numbers, (n) => String(n))
```

### Вывод типов

Компилятор может автоматически выводить параметры типа:

```efen
let result = identity(42)  // T выводится как Int
let doubled = map([1, 2, 3], (x) => x * 2)
```

Подробнее о дженериках см. [Дженерики](generics.md).

## Определение параметров

Параметры функции можно объявить в заголовке либо через `param` в начале тела.
Обе формы являются валидным синтаксисом и обозначают одну модель параметров.
Каждый параметр имеет имя и тип, разделённые двоеточием.
Параметры могут иметь значения по умолчанию, которые используются, если аргумент не был передан при вызове функции:
```efen
fn greet {
    param name: String = "Guest"

    print("Hello, ${name}!")
}
```

Несколько параметров записываются отдельными последовательными объявлениями:
```efen
fn multiply -> Int {
    // Описание для параметра a
    param a: Int
    // Описание для параметра b с значением по умолчанию
    param b: Int = 10

    return a * b
}
```

Каноническую форму выбирает обязательное правило стиля: при числе runtime-
параметров больше трёх используются объявления `param`. Заголовочная форма при
этом остаётся валидной, но получает warning
`S.function-parameter-layout`. Variadic-параметр считается одним; generic-
параметры и неявный receiver не считаются. Общая модель style diagnostics
описана в [Diagnostic Groups](diagnostic-groups.md#style-diagnostics-s).

Все объявления `param` идут подряд в начале тела, до первой инструкции.
Объявление `param` после первой инструкции — ошибка компиляции:

```efen
fn multiply -> Int {
    param a: Int
    let factor = 2     // первая инструкция
    param b: Int = 10  // ошибка компиляции: param после инструкции
    return a * b * factor
}
```

`param` всегда объявляет аргумент вызова. Generic-параметр объявления
записывается отдельным ключевым словом `generic` и предшествует всем `param`:

```efen
fn identity -> T {
    generic T: Type
    param value: T

    return value
}
```

Такая запись сохраняет заголовок коротким и оставляет место для документации
каждого параметра непосредственно перед его объявлением.

`Efen` позволяет не указывать параметры и возвращаемое значение функции, если функция
является частью реализации интерфейса или контракта. В этом случае компилятор использует
определение из интерфейса или контракта для проверки соответствия.

```efen
interface Calculator {
    fn add -> Int {
        param a: Int
        param b: Int
    }

    fn subtract -> Int {
        param a: Int
        param b: Int
    }
}

class SimpleCalculator {
    impliments Calculator

    fn add {
        return a + b
    }

    fn subtract {
        return a - b
    }
}
```

## Переменное число параметров

Переменное число параметров задаётся с помощью синтаксиса:

```efen
fn sum -> Int {
    param numbers: ...Int
    var total: Int = 0
    numbers.for => total += $number
    return total
}
```

Использование функции:

```efen
let result = sum(1, 2, 3, 4, 5)
```

Если требуется передать массив в функцию с переменным числом параметров,
можно использовать оператор распаковки `...`:
```efen
let nums: [Int] = [1, 2, 3]
let result = sum(...nums)
```

Generic-функция может связать гетерогенный pack значений с pack типов:

```efen
fn tuple -> Tuple<...Types> {
    generic ...Types: Type
    param ...values: Types

    return Tuple(...values)
}
```

В `tuple(1, "two")` pack `Types` равен `[Int, String]`. Это отличается от
`numbers: ...Int`, где все runtime-аргументы имеют один тип. Подробные правила —
в [generics](generics.md#pack-значений).

## Значения по умолчанию для параметров

Параметры функции могут иметь значения по умолчанию, 
которые используются, если аргумент не был передан при вызове функции:
```efen
fn greet {
    param name: String = "Guest"

    print("Hello, ${name}!")
}
```

## Вызов функций в стиле команд (без скобок)

`Efen` поддерживает специальный синтаксис вызова функций без скобок, который делает код более читаемым для определённых сценариев, таких как DSL (Domain-Specific Languages), логирование или тестирование.

### Основные правила

Вызов без скобок разрешён в начале инструкции и после знака: `=`, оператора,
открывающей круглой скобки, запятой. После ключевого слова он запрещён, и
вызываемое выражение не может стоять сразу после другого идентификатора.

```efen
// ✅ В начале инструкции
println "Hello, World!"
log "Debug message"

// ✅ После знака
let result = myFun x
let total = base + myFun x
process(myFun x)

// ❌ После ключевого слова
return myFun x     // ошибка компиляции
if isValid x { }   // ошибка компиляции
throw make "boom"  // ошибка компиляции

// ❌ Вызов сразу после идентификатора: цепочка пробельных вызовов
save load path     // ошибка компиляции

// ✅ Вложенный вызов обозначается скобками или явной цепочкой `<|`
save load(path)
save <| load <| path
```

Аргументом становится всё следующее выражение целиком, поэтому
`let result = myFun x + 5` разбирается как `let result = myFun(x + 5)`.

Полные правила разбора и форма `<|` описаны в
[Синтаксис вызова функций](function-call-syntax.md).

### Вызов функции с одним аргументом

Вызов без скобок принимает **одно выражение** в качестве аргумента:

```efen
// Простые литералы
println "Hello"
log 42
debug true

// Сложные выражения
println "Result: " + result
log x + y * 2
assert count > 0 && count < 100

// Замыкания и блоки
test "my test" {
    assert x == 5
}

describe "feature" {
    it "should work" {
        assert result == true
    }
}
```

### Вызов методов без скобок

Синтаксис также работает для методов, включая обращения через точку:

```efen
// Простые методы
logger.info "Application started"
console.error "Failed to connect"

// Цепочки методов
logger.service.info "Processing started"
app.config.db.connect url
user.profile.settings.update data
```

### Когда использовать вызов без скобок

**Рекомендуется использовать** для:
- DSL-подобного кода (тесты, описания)
- Функций логирования и отладки
- Простых команд с одним аргументом

```efen
// DSL для тестов
test "calculator" {
    describe "addition" {
        it "should add numbers" {
            assert add(2, 3) == 5
        }
    }
}

// Логирование
log "Starting process"
println "Done!"
```

**НЕ рекомендуется использовать** для:
- Функций с несколькими аргументами
- Вложенных вызовов
- Сложной бизнес-логики

```efen
// Для нескольких аргументов нужны скобки
myFun(a, b, c)

// Вложенный вызов обозначается скобками
let result = calculate(x) + calculate(y)
```

### Приоритет операторов

При использовании вызова без скобок с выражением, **всё выражение передаётся как аргумент**:

```efen
log x + 5        // Эквивалентно: log(x + 5)
println a * b    // Эквивалентно: println(a * b)
assert x > 0     // Эквивалентно: assert(x > 0)
```

Если нужно вызвать функцию и затем использовать результат в выражении, используйте скобки:

```efen
// Сначала вызов функции, затем оператор
let result = getValue() + 5

// А не так (это ошибка):
let result = getValue + 5  // Ошибка компиляции!
```

## Вызов функций с именованными параметрами

Функции в `Efen` поддерживают именованные параметры, что позволяет явно указывать имена параметров при вызове функции.
```efen
fn greet {
    param firstName: String
    param lastName: String

    print("Hello, ${firstName} ${lastName}!")
}
greet(firstName: "John", lastName: "Doe")
```

## Сигнатуры функций

Сигнатура фунции - это тип данных, описывающий параметры и возвращаемое значение функции.
```efen
type Adder (a: Int, b: Int) -> Int
```

Или альтернативный синтаксис:
```efen
type Adder -> Int {
    param a: Int
    param b: Int
}
```

Сигнатура функции является видом контракта, который существует только во время компиляции.
Сигнатуру функции можно применить как к переменной, параметру, так и к самой функции.

```efen
var myAdder: Adder = (a: Int, b: Int) => a + b

fn add: Adder {
    return a + b
}
```

Сигнатуры функций позволяют определить прототип функции и дать ему имя, 
а после повторно использовать этот прототип для определения функций.

## Эффекты и контексты функций

Функции в `Efen` могут иметь эффекты и контексты, которые определяют поведение функции при её вызове.

Синтаксис:
```efen
fn saveUser in LoggerEffect {
    param name: String

    LoggerEffect.log("Saving user: ${name}")
}
```

Смотреть также [Эффекты и контексты](context-and-effects.md).

## Декораторы функций

Декораторы функций позволяют изменять поведение функций без изменения их кода:

```efen

@attribute
fn compute -> Int {
    param a: Int
    param b: Int

    return a * b
}
```

Когда декораторов очень много, их разумно расположить внутри тела функции:

```efen
fn compute -> Int {
    param a: Int
    param b: Int

    use attribute
    use {
        attribute1
        attribute2
    }
    
    return a * b
}
```

Оператор `use` внутри функции применяет указанные декораторы ко всей функции.
