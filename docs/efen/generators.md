# Генераторы

Генераторы — это функции, которые могут **возвращать промежуточные значения**  
и **возобновляться позже**, сохраняя состояние между вызовами.  
Они позволяют создавать ленивые последовательности, итераторы и сопрограммы.

## Определение генератора

Генераторы объявляются с помощью ключевого слова `generator`.

```efen
generator numbers {
    yield 1
    yield 2
    yield 3
}
```

Ключевое слово `yield` означает:
1. передай значение наружу (в вызывающий контекст);
2. приостанови выполнение;
3. при возобновлении генератора — продолжи с этой точки.

## Использование генератора

```efen
let g = numbers()

match g.next() {
    .yielded.{ let value }: print(value) // первый вызов печатает 1
    .completed.{ let result }: finish(result)
}
```

Последующие вызовы возвращают `yielded(2)`, `yielded(3)`, а затем
`completed(Void)`. Общая форма шага описана ниже.

---

## Передача данных обратно в генератор

Ключевое слово `yield` может использоваться с присваиванием,
чтобы принимать данные, передаваемые в генератор при его возобновлении:

```efen
generator echo {
    msg = yield "ready"
    while msg != "stop" {
        msg = yield "echo: ${msg}"
    }
}
```

## Завершение генератора

Генератор может явно вернуть финальное значение:

```efen
generator counter -> Int {
    i = 0
    while i < 3 {
        yield i + 1
        i = i + 1
    }
    return i
}
```

Значение `return` не отбрасывается. Генератор имеет отдельные типы выдаваемого
значения и итогового результата. После последнего `yield` вызывающий получает
шаг завершения с результатом:

```efen
match g.next() {
    .yielded.{ let value }: use(value)
    .completed.{ let result }: finish(result)
}
```

Таким образом выданное значение и завершение различаются даже при совпадающих
типах. Полный тип генератора также отдельно хранит тип значения, передаваемого
обратно при возобновлении.

## Сравнение с обычными функциями

| Тип функции | Поведение                                       |
|-------------|-------------------------------------------------|
| `fn`        | выполняется один раз и возвращает результат     |
| `generator` | может возвращать множество значений во времени  |
| `return`    | завершает выполнение генератора                 |
| `yield`     | отдаёт значение и приостанавливает выполнение   |

### Связь с функциональным программированием

В языке Efen предусмотрен оператор `|>` для передачи значения вперёд. Оператор
`<|` явно отделяет функцию от её единственного аргумента и не является обратным
пайпом.

```efen
let result = [1, 2, 3]
    |> map((x) => x * 2)
    |> filter((x) => x > 3)

// Явно отделённый единственный аргумент
println <| "Hello, World!"
```

Ключевое слово `yield` в генераторах следует стандартной семантике
из Python, JavaScript и C#, делая код интуитивно понятным для разработчиков.

---

💡 **Итог:**
Ключевое слово `yield` делает генераторы Efen знакомыми и понятными
для разработчиков, знакомых с другими современными языками программирования.
