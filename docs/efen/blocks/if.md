# Условные конструкции

Условные конструкции позволяют выполнять код в зависимости от результата проверки условий.
В `Efen` условные конструкции заимствуют лучшие идеи из Swift, включая if-выражения,
optional binding и возможность использовать if как выражение.

## if как выражение

В `Efen` оператор `if` может использоваться как выражение, возвращающее значение.
Это позволяет писать более компактный и выразительный код.

```efen
let temperature = 25
let weather = if temperature > 30 {
    "Жарко"
} else if temperature > 20 {
    "Тепло"
} else if temperature > 10 {
    "Прохладно"
} else {
    "Холодно"
}

print(weather) // "Тепло"
```

Когда `if` используется как выражение, все ветви должны возвращать значение совместимого типа.

## Простое условие

Базовая форма условного оператора:

```efen
let age = 18

if age >= 18 {
    print("Совершеннолетний")
}
```

## if-else

Условие с альтернативной ветвью:

```efen
let age = 15

if age >= 18 {
    print("Совершеннолетний")
} else {
    print("Несовершеннолетний")
}
```

## if-else if-else

Множественные условия:

```efen
let score = 85

if score >= 90 {
    print("Отлично")
} else if score >= 80 {
    print("Хорошо")
} else if score >= 70 {
    print("Удовлетворительно")
} else {
    print("Неудовлетворительно")
}
```

## Optional Binding

`Efen` поддерживает optional binding в условиях, что позволяет безопасно работать
с optional значениями. Это одна из лучших идей из Swift.

```efen
let optionalName: String? = "Иван"

if let name = optionalName {
    print("Привет, ${name}!")
} else {
    print("Имя не указано")
}
```

### Множественное optional binding

Можно проверять несколько optional значений одновременно:

```efen
let optionalName: String? = "Иван"
let optionalAge: Int? = 25

if let name = optionalName, let age = optionalAge {
    print("${name}, возраст: ${age}")
} else {
    print("Недостаточно данных")
}
```

### Optional binding с условиями

Можно комбинировать optional binding с дополнительными условиями:

```efen
let optionalAge: Int? = 25

if let age = optionalAge, age >= 18 {
    print("Совершеннолетний, возраст: ${age}")
} else {
    print("Несовершеннолетний или возраст неизвестен")
}
```

## Логические операторы

### Оператор И (&&)

```efen
let age = 25
let hasLicense = true

if age >= 18 && hasLicense {
    print("Может водить машину")
}
```

### Оператор ИЛИ (||)

```efen
let isWeekend = true
let isHoliday = false

if isWeekend || isHoliday {
    print("Выходной день")
}
```

### Оператор НЕ (!)

```efen
let isRaining = false

if !isRaining {
    print("Можно идти гулять")
}
```

### Комбинирование операторов

```efen
let age = 25
let hasTicket = true
let isVIP = false

if (age >= 18 && hasTicket) || isVIP {
    print("Допуск разрешён")
}
```

## Короткая форма if (тернарный оператор)

`Efen` поддерживает тернарный оператор для простых условий:

```efen
let age = 20
let status = age >= 18 ? "Взрослый" : "Ребёнок"
```

Выбор формы задаёт правило стиля: тернарный оператор пишется, когда обе ветви —
простые выражения на одной строке; `if`-выражение — когда ветвь является блоком
или занимает несколько строк. Отклонение в любую сторону получает диагностику
стиля. Вложенный тернарный оператор пишется только в скобках:

```efen
let level = score > 90 ? "A" : (score > 70 ? "B" : "C")
```

После тернарного `?` стоит пробел. `?.`, `?[` и `?(` — токены optional-доступа;
пробел перед `?(` или `?[` является ошибкой синтаксиса, потому что запись
читается и как optional-вызов, и как тернарный оператор:

```efen
let y = ready?(a)          // optional-вызов
let x = ready ? (a) : b    // тернарный
let z = ready ?(a) : b     // ошибка: неоднозначно
```

## Вложенные условия

Условия могут быть вложенными:

```efen
let age = 25
let hasLicense = true
let hasCar = true

if age >= 18 {
    if hasLicense {
        if hasCar {
            print("Может поехать на своей машине")
        } else {
            print("Может взять машину в аренду")
        }
    } else {
        print("Нужно получить права")
    }
} else {
    print("Слишком молод для вождения")
}
```

Однако, вложенные условия часто можно заменить на более читаемый код
с использованием логических операторов или `guard` (см. [guard.md](guard.md)).

## Условия без скобок

В `Efen` скобки вокруг условия не обязательны (как в Swift):

```efen
let x = 5

if x > 0 {
    print("Положительное число")
}
```

Это делает код более чистым и читаемым.

## Безопасность типов

Условие в `if` должно иметь тип `Bool`. Неявное преобразование к булевому типу не поддерживается:

```efen
let count = 5

// ❌ Ошибка: условие должно быть Bool
// if count {
//     print("Count is non-zero")
// }

// ✅ Правильно
if count > 0 {
    print("Count is non-zero")
}
```

Это помогает избежать распространённых ошибок и делает код более явным.

## Использование с optional

При работе с optional типами можно использовать различные подходы:

### Проверка на null

```efen
let optionalValue: Int? = 42

if optionalValue != null {
    print("Значение: ${optionalValue!}")
}
```

### Optional binding (рекомендуется)

```efen
let optionalValue: Int? = 42

if let value = optionalValue {
    print("Значение: ${value}")
}
```

### Короткая форма с ??

```efen
let optionalValue: Int? = 42
let value = optionalValue ?? 0

if value > 0 {
    print("Положительное значение: ${value}")
}
```

## Рекомендации

1. **Используйте if-выражения** когда нужно вернуть значение на основе условия
2. **Предпочитайте optional binding** вместо явной проверки на null
3. **Избегайте глубокой вложенности** — используйте early return или guard
4. **Используйте логические операторы** вместо вложенных if, когда это уместно
5. **Не используйте скобки** вокруг условий, если они не нужны для группировки
6. **Будьте явными** — не полагайтесь на неявное преобразование типов
