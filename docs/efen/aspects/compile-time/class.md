# Описание классов

Классы в `Efen` наследуют удачную концепцию классов из `Java`, `PHP`, которая позволяет
описать множество случаев через философию соединения структуры данных, функций и линейного наследования.
На низком уровне классы могут быть реализованы по-разному в рамках `Efen`-модели (без множественного наследования).

Классы в `Efen` могут быть ARC-объектами с автоматическим управлением памятью и сборкой мусора, 
которой программист может управлять, если захочет. Но могут и не быть. В конце концов сборщика мусора может и не быть.
А может быть совершенно другой сборщик мусора, не основанный на ARC-объектах.

По-умолчанию `Efen` поставляется с `limelight`-runtime, 
который и реализует ARC-объекты с автоматическим управлением памятью и сборкой мусора.
Если вы используете `limelight`-runtime, вы сможете создавать объекты без `ARC`, но вероятно не сможете 
создать объекты с другим `ARC`, так как структуры данных `limelight`-runtime нужны как сборщику мусора так и менеджеру памяти.

Иначе говоря `limelight` ограничивает вас в выборе менеджера памяти, сборщике мусора и в базовой структуре ARC.
С другой стороны вы можете реализовать собственный менеджер памяти, собственный сборщик мусора и собственную структуру ARC.
Именно для этого и нужен механизм, описанный ниже.
Он будет полезен так же и в том случае, если требуется кастомизировать поведение класса, определить уникальные 
возможности или поведение прямо на уровне компилятора.

## Аспект класса

Чтобы иметь возможность определять классы `Efen` с нуля, требуется определить аспект, реализующий контракт `ClassDefinition`.
По сути реализация этого аспекта и говорит компилятору, что данный аспект будет использоваться для создания классов `Efen`.


## ClassDefinition

Встроенный контракт `ClassDefinition` обязан быть реализован любым классом `Efen` через аспект.
По-умолчанию его реализацией является `limelight`-runtime, если он подключен.

```efen
contract ClassCompilation {
    fn primaryClassDefinition(class: lang::Class) in compiler
    fn finallyClassDefinition(class: lang::Class) in compiler
}
```

Результатом работы аспекта является структура `lang::Class`, 
которая содержит информацию о классе, его свойствах и методах.

## lang::Class

Структура `lang::Class` является внутренней структурой данных `Efen`, и реализована 
как часть репозитория `Amber`. `Amber` представляет собой High-level Intermediate Representation (`HIR`) для языка `Efen`, 
которая используется компилятором для анализа и генерации кода.

## ClassDefinitionHandler

`ClassDefinitionHandler` используется, чтобы внести точечные изменения в определение класса `Efen`.
Его методы вызываются после ClassCompilation::primaryClassDefinition и до ClassCompilation::finallyClassDefinition.
`ClassDefinitionHandler` позволяет установить обработчик interceptor, 
который будет вызван на одном из этапов `ClassDefinitionPlan`.

```
contract ClassDefinitionHandler {
    fn beforeClassDefinition(plan: compiler::Class::ClassDefinitionPlan) in compiler
}

// fn addInterceptor(plan: compiler::Class::ClassDefinitionPlan, compiler::Class::ClassDefinitionInterceptor, step) in compiler
contract ClassDefinitionInterceptor {
    fn intercept(class: lang::Class) in compiler -> lang::Class
}
```
