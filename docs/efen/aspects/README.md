# Метапрограммирование: аспекты и преобразования

[Документация](../README.md) · [Словарь](../glossary.md) · [Compile-time API](../compile-time/README.md)

В Efen публичное поведение и преобразование декларации на этапе компиляции —
разные механизмы. Контракты, interfaces и стратегии описывают обычную модель
типов; этот раздел описывает метапрограммирование.

## Выберите механизм

| Задача | Документ |
|---|---|
| Преобразовать декларацию на этапе компиляции | [Аспекты](aspect.md) |
| Управлять тем, как находятся члены | [Разрешение членов](members-resolving.md) |
| Добавить декларативные данные к элементу программы | [Metadata](metadata.md) |

## Аспекты по порядку

1. [Аспекты](aspect.md) — область действия, требования и права на изменение.
2. [Построение класса](compile-time/class.md) — границы стадий и создание
   класса compile-time кодом.
3. [Разрешение членов](members-resolving.md) — extension-точки, которые не
   добавляют член в класс автоматически.
4. [Metadata](metadata.md) и [декораторы](../decorators.md) — аннотации и их
   обработка.

Для обхода и преобразования HIR используйте [Compile-time API](../compile-time/README.md).
Правила о модели класса находятся в [классах](../classes.md), а не в этом
каталоге. Для обычного расширения поведения используйте [контракты](../contracts.md),
[interfaces](../interfaces.md) и [стратегии](../strategies.md).
