# Правила доступа к памяти: сводная таблица

[Документация](../README.md) · [Словарь](../glossary.md) · [Владение и доступ](../types/ownership.md) · [Области доступа](../types/access-regions.md) · [Компоновка](layout-reference.md)

> Статус: таблица составлена 2026-11-11. Правила здесь не вводятся: каждая строка называет статью, где правило записано. Там,
> где статьи расходятся, действует эта таблица; расхождения перечислены в [последнем разделе](#расхождения-статей-с-таблицей).

Доступ к памяти в Efen описывают три понятия и одна главная операция. Слот хранит значение. Ссылка даёт доступ к
слоту с правом и источником. Заимствование в структуре — доступ, который действует дольше вызова: его хранит структура, которая заимствует. Изменение структуры — операция, после которой слот перемещён или уничтожен. После него ссылка и заимствование становятся недействительными; остальные строки таблицы [«Что делает ссылку недействительной»](#что-убивает-ссылку) — конец времени жизни слота, заморозка и точка ожидания.

**Основа всех таблиц.** Два поля или два параметра указывают в одну память, только если это объявлено явно. Механизмов
объявления два: право с источником, `право<поле или параметр>`, и `layout`
([поля не делят память](../types/ownership.md#поля-не-делят-память)). Без объявления поле владеет своим значением, а
пишущие аргументы не пересекаются. Из этого следует правило: вызов, который меняет одно поле, оставляет действительными ссылки в другое поле.

## Понятия

| Понятие | Что это | Чем владеет | Где описано |
|---|---|---|---|
| слот | то, где хранится значение: переменная, параметр, поле, элемент; имеет адрес и время жизни | своим значением | [ownership.md](../types/ownership.md) |
| ссылка | доступ к слоту с правом `read`, `edit` или `mut` и с источником; существует только внутри функции | ничем | [ссылки только внутри функции](../types/ownership.md#ссылки-только-внутри-функции) |
| источник | слот или путь внутрь него, от которого ссылка взята; по нему компилятор определяет, какие операции делают её недействительной | — | [источник, право и время действия](../types/access-regions.md#источник-право-и-время-действия) |
| псевдоним | имя, связанное с уже существующим значением без копии: `let t = doc.title`, переменная образца; действителен столько же, сколько ссылка `read` | ничем | [ownership.md](../types/ownership.md) |
| срез, диапазон | ссылка на несколько соседних слотов одного источника: `&v[i..<j]`; правила те же, что у ссылки | ничем | [диапазон как цель права](../types/access-regions.md#диапазон-как-цель-права) |
| заимствование в структуре | заимствование, которое действует дольше вызова: у курсора, генератора, замыкания — право и источник в типе; у внешнего кода — запись модели в поле `layout` | ничем | [контракты обхода](../types/collections.md#контракты-обхода), [модели](../models.md#заимствования) |
| часть | имя памяти объекта в контракте; без типа и байт | привязанными полями и всем, чем они владеют прямо или через другие значения | [части объекта](../types/parts.md) |
| проекция | тип с выбранными полями значения | ничем: проекция даёт доступ к выбранным полям значения | [проекции](../types/projection.md) |
| множество, область | `set X` — все элементы одной формы во всей программе, своей памяти у множества нет; `area X` — непрерывные слоты по индексу | область — своими слотами; элементом множества владеет якорь или функции | [компоновка](layout-reference.md) |
| невладеющий указатель | указатель на элемент `S.Item` без владения: поле `layout`, локальная переменная, параметр, результат, поле структуры с `Src`; источник — структура, из которой он прочитан; указатель в множество без поля-владельца имеет источником это множество | ничем | [структура, источник, чистота](layout-reference.md#структура-источник-чистота) |
| якорь | неисключительное владение `anchor`: точка уничтожения значения, на которое указывают невладеющие указатели; переходит из слота в слот через `tie` | значением | [компоновка](layout-reference.md#якорь-anchor) |
| поле-псевдоним | поле `R<self.путь> T?`: поле, которое указывает в память своего же объекта; ссылкой и заимствованием не считается, принадлежит части своего источника | ничем | [поле-псевдоним](../types/ownership.md#поле-псевдоним) |
| структура | корень цепочки владения элемента: вверх по `anchor`, `own`, вложенности в область и полю-значению `layout`, пока очередной владелец не окажется вне `layout`; у элемента без владельца — его множество; хранимый невладеющий указатель указывает только внутрь своей структуры или в множество без поля-владельца (чистота) | — | [структура, источник, чистота](layout-reference.md#структура-источник-чистота) |
| исходная память множества | память, из которой взяты элементы множества: память ОС, область родителя; не то же, что источник ссылки | — | [время жизни](layout-reference.md#время-жизни) |

## Права

| Право | Читать | Писать значения | Создавать слоты, не двигая существующих | Перемещать и уничтожать слоты | Забрать значение |
|---|---|---|---|---|---|
| `read` (умолчание) | да | — | — | — | — |
| `edit` | да | да, если прежнее значение ничем не владеет | да | — | — |
| `mut` | да | да | да | да | `take` из опционального слота (в нём остаётся `null`) и `take` элемента области (элемент не инициализирован; к выходу публичной функции он по инварианту владельца не входит в занятые) |
| `own` | да | да | да | да | да |
| `out` | — | первая запись в неинициализированный слот | — | — | — |

- `edit` разрешает менять значения и гарантирует, что память структуры никуда не перенесена. `mut` разрешает всё,
  что `edit`, и этой гарантии не даёт. Гарантия относится ко всей памяти структуры, служебной тоже: рост массива из
  блоков, при котором переехал только каталог блоков, — `mut`.
- `edit` имеет смысл только у структур данных: у значения, которое не владеет памятью, `edit` и `mut` не различаются.
- Перестановка указателей, при которой ни один слот не перенесён и не уничтожен, — `edit`: перенос узла в начало
  списка давности оставляет ссылки на узлы действительными. Это относится и к якорям: `tie`, после которого элемент принадлежит той же структуре, — `edit`. Элемент переходит в другую структуру только владением: это `mut` для структуры, из которой он
  ушёл, и `edit` для той, куда пришёл; скопировать указатель в другую структуру нельзя.
- `mut` забирает значение из опционального слота и из элемента области; забрать значение из обычного поля может `own` на
  содержащий объект или `replace` и `swap`, которые сразу записывают другое.
- Объекты со счётчиком (`conforms ArcClass`) подчиняются своим правилам: время жизни задаёт счётчик, и правило «общая
  память только по объявлению» к ним не относится; два поля такого типа компилятор считает возможно одним объектом. Все операции компоновки по правам
  разложены в таблице [«`edit` и `mut` в `layout`»](layout-reference.md#edit-и-mut-в-layout).
- Запись под `edit` значения, которое владеет памятью (строка, вложенный вектор, опциональное значение, вариант),
  уничтожила бы старую память, поэтому требует `mut` ([права](../types/access-regions.md#права)).
- `anchor` — неисключительное владение в `layout`, а не право доступа: точка уничтожения значения, на которое указывают хранимые указатели ([компоновка](layout-reference.md)).
- После приведения памяти к виду `as` поля не инициализированы: инициализация явная — в самом приведении
  (`as Item(value: 0, next: NONE)`), записью кодом или грязным инициализатором `_` (`as Item(value: _, next: NONE)`);
  обращение к неинициализированному полю — ошибка ([виды и приведение](layout-reference.md#виды-и-приведение-as)).
- `immutable T` — свойство слота, а не право: значение и всё, чего оно достигает, не меняется; заморозка `take x` в такой слот делает недействительными все ссылки и псевдонимы из `x` ([неизменяемость](../immutability.md)).
- `mut` не исключителен: несколько ссылок `mut` в один источник действительны одновременно, пока структура источника не изменена.
- На поле `foreign` бывает только `read` и `mut`: перезапись буфера кодом C делает прежнюю ссылку недействительной и поэтому считается изменением структуры ([внешний код](../foreign.md)).

## Где пишется право

| Позиция | Запись | Что называет | Несколько путей |
|---|---|---|---|
| параметр | `list: mut Vector<Shape>` | что функция делает с аргументом | — |
| отношение параметров | `src: read<dst?> T` | на какой параметр может указывать аргумент | варианты |
| получатель метода | `mut fn`, `edit fn`, `read fn`, `own fn` | что метод делает с `self` | — |
| получатель с путём | `mut<self.cache> fn`, `mut<self.cache, edit self.items> fn` | части и поля, которые метод изменяет; остальное он читает | все названные |
| ссылка в результате | `-> edit<list> Shape?`; в методе `-> read Shape?`, `-> read<self.items> Item?` | источник отданной ссылки | нет |
| ссылка ровно на слот в результате | `-> read<&doc.title> Vector<Pair>` | сам слот по пути: ссылка остаётся действительной после изменения структуры внутри слота и записи слота целиком ([ссылка ровно на слот](../types/ownership.md#ссылка-ровно-на-слот)) | нет |
| роль `yield` | `yield edit<items> Item` | источник отданной ссылки | нет |
| заимствование в скобках | `(Access<self> Cursor)`, `(mut<items> generator yield Int)` | что значение заимствует, пока существует | все названные |
| поле структуры с источником | `let items: Access<Src> Array<T>` | то же заимствование, записанное полем; право заимствования типа — самое широкое среди таких полей | — |
| поле-псевдоним | `var current: read<self.children> Node?`, `read<self> T?` | куда в своём объекте указывает поле; заимствования типу не даёт | — |
| указатель в параметре и результате | `v: edit S.Item`, `v: mut S.Item`, `node: anchor S.Item`, `-> own Block.data.Item`, `from: read<g> Nodes.Item` | право на элемент и, с `<g>`, структуру, которой он принадлежит | — |
| эффект на единственный экземпляр `one X` | `in edit Registry`, `in mut Registry` | что функция делает с памятью за `one`; с телом выводится | — |
| владение, которое блок отдаёт внешнему коду | `public own Nodes`, `public lend Block.data` в `layout` | какие элементы уходят целиком (`own S.Item`) и слоты каких областей выдаются (`lend`); якорь внешнему коду не выдаётся; FLOW проверяет по сводке каждую функцию, видимую внешнему коду, и требует функцию обратного пути ([схема владения](layout-reference.md#схема-владения)) | — |
| тип колбэка | `mut<items> (Int) -> Void` | память, структуру которой колбэк может менять | вся названная |
| заголовок `for` | `for x in edit v`, `for x in mut v` | право на коллекцию, с которым вызывается `iterator` | — |
| ссылка в выходном параметре | `p: out read<q> T?` | ссылку с источником `q`, которую функция пишет в слот вызывающего | нет |
| ссылка в теле | `&x`, `&read x` | `&x` берёт право слота `x`: под параметром `edit` это `edit`, под `mut` и у своей переменной — `mut`; `&read x` сужает до `read` | — |

Ссылка не шире права области, из которой взята. Полная таблица записи `право<путь>` — в [областях доступа](../types/access-regions.md#источник-право-и-время-действия).

## Что делает ссылку недействительной

Когда у источника меняется структура (элемент удалён, память перевыделена, значение заменено), все ссылки в него
становятся недействительными. Менять структуру можно и при действительной ссылке, если после этого ссылку больше не читают и не
пишут. Если ссылку используют после изменения, компилятор выдаёт ошибку.

```efen
let first = &v[0]
v.append(1)          // может перевыделить память v: first становится недействительной
print(first)         // ошибка: first используется после изменения v
```

Курсор и генератор, которые заимствуют источник, подчиняются тому же правилу. Если после изменения они больше не нужны,
компилятор уничтожает их прямо перед изменением, и их `defer` выполняется там же; если они нужны после — ошибка
([явное извлечение](../types/ownership.md#явное-извлечение)).

Что именно вызов меняет, компилятор берёт из сводки функции, когда тело видно: метод `mut fn`, который меняет структуру одного поля, делает недействительными ссылки только в это поле. Когда тела нет — метод контракта и интерфейса, `open`-метод, тип функции, значение из другого
пакета — компилятор берёт это из сигнатуры: слово права, путь при нём, право заимствования в типе.

| Операция | Что становится недействительным | Где описано |
|---|---|---|
| вызов `read` | ничего | [как компилятор выводит области](../types/access-regions.md#как-компилятор-выводит-области) |
| вызов `edit` | ничего: значения записаны, слоты на своих адресах; факты о значениях забыты | там же |
| вызов `mut`: метод у получателя, функция у аргумента параметра `mut`, код с эффектом `in mut Ctx.field` | с телом — ссылки в то, структуру чего тело меняет; без тела — каждая ссылка в объект и во всё, что вызов может изменить ([следующий раздел](#до-чего-доходит-вызов-mut)) | там же |
| вызов `mut<self.cache> fn` | ссылки в названные части, ссылки с источником `self` без пути, ссылки в части контракта, не связанного наследованием, и ссылки в то, что вызов может изменить через поля `layout` с `mut`; ссылки в остальные части того же контракта остаются действительными | [что видит вызывающий](../types/parts.md#что-видит-вызывающий) |
| вызов с параметром типа проекции | ссылки в поля проекции по праву параметра; ссылки в остальные поля остаются действительными | [проекция в параметре](../types/projection.md#проекция-в-параметре) |
| шаг курсора или генератора (`next`, шаг `for`) | это вызов `mut` у курсора: при заимствовании `mut` — ссылки в источник, при `read` и `edit` — ничего | [контракты обхода](../types/collections.md#контракты-обхода), [отдача ссылки](../generators.md#отдача-ссылки) |
| уничтожение значения с заимствованием `mut` | то же, что вызов `mut` у него | там же |
| `yield` в теле генератора | для тела это вызов неизвестного кода: факты о значениях забыты; при `mut` — ссылки кадра в источник | [отдача ссылки](../generators.md#отдача-ссылки) |
| вызов `mut fn` класса над внешним значением, в том числе через получателя `edit` | ссылки с источником во внешнем объекте: считается право, написанное у метода, а не право получателя | [класс над внешним значением](../classes.md#класс-над-внешним-значением) |
| вызов через тип функции без права `mut<…>` | ничего: такая функция структуру аргументов не меняет | [тип функции](../types/function-type.md) |
| присваивание значения, которое владеет памятью, опционального значения или варианта; `slot = null` | ссылки внутрь прежнего значения; ссылка на сам слот действительна | [совместимость](../types/access-regions.md#совместимость) |
| `replace(slot, v)`, `swap` | то же, что присваивание: ссылки внутрь прежнего значения; ссылка на слот действительна | там же |
| точка ожидания в однопоточном контексте | всё, что по сводкам меняют незавершённые корутины, как при вызове с такой сводкой; ссылки в контекст потока — всегда | [корутины `spawn`](../types/access-regions.md#корутины-spawn) |
| отпускание блокировки: выход из `with`, исключение, конец вызова замыкания `waitFor` | указатели, ссылки и заимствования с источником в охраняемых полях; значение, которое хранит такой указатель, ссылку или заимствование и дальше не используется, уничтожается до `exit`, используемый — ошибка | [структура под блокировкой](layout-reference.md#структура-под-блокировкой) |
| многопоточная корутина, сводка которой меняет источник указателя, ссылки или заимствования, действительных на её отрезке | ошибка компиляции: такой доступ считается `read` источника на весь отрезок; компилятор показывает ошибку в строке `spawn` и отдельно строку использования | [структура и поток](layout-reference.md#структура-и-поток) |
| `take x` целой локальной переменной в новую переменную | ничего: слот остался в функции, ссылка указывает на слот, а не на имя | [явное извлечение](../types/ownership.md#явное-извлечение) |
| `take x` в существующий слот | все ссылки на слот-источник | там же |
| `take` из опционального поля или элемента | ссылки внутрь прежнего содержимого: в слоте остался `null` |
| `take` элемента области | ссылки и указатели на этот элемент; элемент не инициализирован | [неинициализированный элемент области](layout-reference.md#множества-и-области) |
| выход из области со структурой, у которой владеющее поле `layout` может быть не `null`, в том числе через исключение | ошибка компиляции; закрывает `defer v.release()` | [уничтожение структуры из `layout`](layout-reference.md#пространство-layout) | [что делает ссылку недействительной](../types/ownership.md#что-делает-ссылку-недействительной) |
| `tie` якоря, после которого элемент принадлежит той же структуре (перестановка) | ничего: элемент на своём адресе, изменилась точка уничтожения | [`edit` и `mut` в `layout`](layout-reference.md#edit-и-mut-в-layout) |
| элемент ушёл из структуры владением: в результат, в другую структуру | указатели и ссылки с источником в этой структуре на него и на всё, что под ним, в любом коде; в функции, которая сама передала элемент и знает, куда, её локальный указатель получает источником новую структуру | [структура, источник, чистота](layout-reference.md#структура-источник-чистота) |
| `lend` слота (это `mut` на родителя) | ссылки, срезы и курсоры, которые могут пересекаться с выданным слотом | [выдача и возврат](layout-reference.md#выдача-и-возврат) |
| вызов без тела с параметром `mut S.Item` или с правом `mut` на структуру | указатели с источником в структуре аргумента и указатели в множества без поля-владельца того же `layout` | [структура, источник, чистота](layout-reference.md#структура-источник-чистота) |
| `as own`, освобождение элемента, возврат выданного слота, смена вида `as` | все ссылки и указатели на элемент; хранимые указатели переписаны до этой операции, иначе ошибка в её строке | [переход к владению](layout-reference.md#переход-к-владению-as-own) |
| вызов функции, сводка которой освобождает элемент или забирает его из структуры | указатели и ссылки, которые могут быть равны этому элементу, — в строке вызова; так же, когда функция делает это через `one` | [якорь](layout-reference.md#якорь-anchor) |
| уничтожение исходной памяти множества (возврат блока, региона) | ссылки и указатели на всё, что из неё взято; выданный наружу слот `own` или заимствование в структуре вне этой памяти — ошибка в строке возврата | [вложенность](layout-reference.md#вложенность) |
| изменение структуры источника поля-псевдонима | поле-псевдоним: функция, которая меняет источник, записывает поле заново до первого чтения и до каждого выхода, иначе ошибка в ней | [поле-псевдоним](../types/ownership.md#поле-псевдоним) |
| элемент перемещён (`insert`, сжатие, перевыделение); перенос пишет код: `take` из старого элемента и запись в новый | ссылка, путь которой проходит через этот элемент; она недействительна со строки `take`. Ссылки в память, которой значение владеет через указатель (буфер строки), остаются действительными: значение перенесено, буфер — нет | [неинициализированный элемент области](layout-reference.md#множества-и-области) |
| слот покидает функцию: `own`-параметр, результат, поле, захват `spawn` | все ссылки на него | там же |
| заморозка: `take x` в слот `immutable T` | все ссылки и псевдонимы из `x` | [неизменяемость](../immutability.md) |
| операция представления `free` | ссылки на слот и на всё, чем он владеет; хранимые невладеющие указатели на него переписаны до операции, иначе ошибка в её строке | [одна модель с `layout`](../types/access-regions.md#одна-модель-с-layout) |
| конец блока, где объявлена переменная | ссылки на её слот; ссылка время жизни слота не продлевает | [как компилятор выводит области](../types/access-regions.md#как-компилятор-выводит-области) |

<a id="до-чего-доходит-вызов-mut"></a>

## Что может изменить вызов `mut`

| Что вызов может изменить | С каким правом | Пример |
|---|---|---|
| сам получатель и всё, чем он владеет | `mut` | после `v.append(x)` ссылка `&v[0]` недействительна |
| объект за полем `layout` с правом `mut` | `mut`, и дальше по таким же полям этого объекта | после `s.sqlite3_step()` ссылка `read<db.errmsg>` недействительна: `s.db` — `mut sqlite3` |
| источник заимствования в скобках | с правом заимствования, не шире | `g.next()` у `(mut<items> generator …)` делает недействительными ссылки в `items`; у `(edit<items> generator …)` — нет |
| источник в поле `R<Src> …` структуры | с правом `R` | курсор с полем `mut<Src> Array<T>` |
| источник по цепочке заимствований | с самым узким правом на цепочке | курсор заимствует генератор с `mut`, генератор заимствует `items` с `edit`: шаг курсора меняет `items` с правом `edit` |
| объект за полем `layout` с правом `read` или `edit`, источник заимствования `read` или `edit` | структуру изменить не может | после шага обычного курсора ссылки на элементы действительны |
| объект со счётчиком | ссылки внутрь объекта после вызова действительны: объектом владеют все ссылки со счётчиком; ссылки внутрь становятся недействительными, когда заменена сама ссылка со счётчиком | [проверка привязки](../types/parts.md#проверка-привязки) |

Заимствование `mut` не теряется ни при каком преобразовании: значение с ним передаётся только в параметр, в типе которого это заимствование записано.

## Два доступа сразу

| Пара | Правило | Если не доказано |
|---|---|---|
| два поля одного объекта, поля двух объектов, два элемента коллекции, два параметра | не пересекаются, пока общая память не объявлена правом с источником или `layout` | — |
| два читающих аргумента | делят память свободно | — |
| читающий аргумент `ImplicitlyCopyable` и любой другой | передаётся копией и ни с чем не пересекается | — |
| пишущий аргумент (`edit`, `mut`, `out`, `own`) и другой аргумент | не пересекаются, если сигнатура не объявила отношение «внутри» | проверка адресов при вызове, сбой `OverlapError` |
| получатель с путём и аргумент-ссылка | сравниваются по частям | ошибка компиляции: у части нет адреса |
| два аргумента-проекции одного значения | не пересекаются, если поля `var` одной не входят в другую | проверка адресов по полям |
| захват многопоточной корутиной и остальной код | только доказательство | ошибка компиляции |
| владелец и структура, которая заимствует с правом `read` или `edit` | владелец читает и пишет значения, создаёт слоты; к изменению структуры применяется правило раздела [«Что делает ссылку недействительной»](#что-убивает-ссылку) | — |
| владелец и структура, которая заимствует с правом `mut` и которую реализация возвращает для заимствования из контракта | владелец меняет структуру; структура, которая заимствует, хранит только слот получателя и остаётся действительной | — |
| владелец и конкретный курсор, который сам двигает слоты (`removing()`, `draining()`) | менять источник можно только через курсор; изменение структуры в обход курсора делает его недействительным | — |
| два параметра `edit` или `mut` одного множества (`a: mut S.Item, b: mut S.Item`) | `apart`: сравниваются названные элементы; достижимость по указателям в сравнение не входит; случай «один элемент» — отдельная ветка | проверка адресов |
| владелец и курсор с полем `read<Src> S.Item?` | после вызова `edit` у владельца (вставка, перестановка) курсор действителен; вызов, который освобождает элементы или забирает их из структуры, делает курсор недействительным | — |
| объект и его поле-псевдоним | объект остаётся владельцем источника и меняет его структуру; поле записывается заново | — |
| две структуры, которые заимствуют один источник | как две ссылки с теми же правами: действительны одновременно; изменение структуры через одну делает недействительной другую | — |
| части одного контракта и его предков | не пересекаются: проверено привязкой | — |
| части двух контрактов, не связанных наследованием | считаются пересекающимися | — |
| структура и поток | структура — одна область: корень и все элементы под ним; право, выполненное через указатель с этим источником, — доступ к области с этим правом | ошибка компиляции ([структура и поток](layout-reference.md#структура-и-поток)) |
| множество без владельца, `one` и поток | множество или `one` — одна область на всю программу; доступ через указатель с источником в множестве и эффект `in read\|edit\|mut X` сверяются по таблице многопоточного вида | ошибка компиляции ([множества без владельца и `one`](layout-reference.md#множества-без-владельца-и-one)) |
| поток и поток | части ссылок не разделяют потоки: метод с путём конфликтует с любым другим методом объекта | [общая память](../shared.md) |

## Обход

| Заголовок | Заимствование курсора | Тело цикла может | После шага ссылки на прежние элементы недействительны |
|---|---|---|---|
| `for x in v` | `(read<v> Cursor)` | читать `v`; владелец с правом записи пишет значения и создаёт слоты | нет |
| `for x in edit v` | `(edit<v> Cursor)` | писать значения, создавать слоты, не двигая существующих | нет |
| `for x in mut v` | `(mut<v> Cursor)` | менять структуру `v`; ссылка на элемент действительна до первого такого изменения | да |
| `for x in take v` | нет: курсор владеет `v` | `x` — значение, а не ссылка | — |
| `for x in курсор` | какое записано в его типе | по праву заимствования; курсор берётся как `mut`, слово права не пишется | по праву заимствования |
| `for x in генератор` | какое записано в его типе | по праву заимствования; генератор берётся как `mut` | по праву заимствования |
| `for item in let c = items.removing()` | конкретный тип, который сам двигает слоты | менять `items` только через `c` | да |

- Курсор, который реализация возвращает для заимствования `mut` из контракта, из полей с `Src` хранит один слот получателя.
- `next` возвращает элемент или `null`; цикл снимает один уровень опционального типа, поэтому элемент `null` — не
  конец обхода ([цикл `for` с итератором](../types/collections.md#цикл-for-с-итератором)).
- Генератор контрактов обхода не соблюдает; итератор для обобщённого кода даёт его метод `iterator()`
  ([генератор как итератор](../generators.md#генератор-как-итератор)).

## Что пишет программист и что выводит компилятор

| Факт | В функции и методе с телом | В контракте, интерфейсе, объявлении без тела |
|---|---|---|
| право параметра и слово права метода | пишется | пишется |
| что именно тело изменяет (сводка, путь до поля) | выводится | пишется путём при слове права |
| источник ссылки в результате и в роли `yield` | пишется | пишется |
| источник локальной ссылки | выводится из выражения `&` | — |
| заимствование значения-результата | пишется в типе результата | пишется в скобках |
| заимствование генератора-метода | выводится из тела; путь при слове права — проверяемый предел | пишется путём при слове права |
| привязка частей к полям | пишется, включая `= none` | — |
| непересечение аргументов | доказывается; иначе проверка адресов | то же |
| время жизни невладеющих указателей, предусловия операций над слотами | выводится из `layout` | пишется условиями `layout` |
| эффекты и исключения | выводятся | пишутся |

## Где доказательство, где проверка при выполнении

| Свойство | Доказано | Не доказано |
|---|---|---|
| ссылка не использована после изменения структуры источника | компилируется | ошибка компиляции |
| пишущий аргумент не пересекается с другим | компилируется | проверка адресов, `OverlapError` |
| то же для частей и для захвата многопоточной корутиной | компилируется | ошибка компиляции |
| индекс в границах | проверки нет | проверка при выполнении |
| безопасность операции компоновки (освобождение, перевыделение, `tie` якоря, `as own`) | компилируется | ошибка компиляции |
| отданная генератором ссылка указывает в объявленный источник | компилируется | ошибка в строке `yield` |
| точки доверия (`@asm`, внешний код, `@fill`) | — | принимаются без доказательства; их перечисляет `efen proofs` |

## Чего таблица не обещает

Таблица описывает модель, но доказательства надёжности у модели нет: [алгоритм](layout-algorithm.md) даёт план
доказательства, а не выполненное. Два раунда Критика 2026-11-11 находили в свежих правилах принятые программы с
обращением к освобождённой памяти; правила после них исправлены, но известное отсутствие таких программ — не
доказательство. Вне модели сегодня:

| Область | Состояние |
|---|---|
| структуры без блокировок; освобождение блока mm из другого потока; объекты со счётчиком | вне `layout`: примитивы стандартной библиотеки, доказанные один раз; объекты со счётчиком — отдельная тема ([что `layout` не описывает](layout-reference.md#чего-layout-не-описывает)) |

Не нарушают надёжность: утечка элемента без владельца, проверки при выполнении (граница индекса, `OverlapError`,
порядок вызовов генератора) и отказ принять безопасную программу.
