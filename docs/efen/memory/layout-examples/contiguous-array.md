# Непрерывный массив фиксированной длины

[К примерам](README.md) · [Исходник](contiguous-array.efen) ·
[Пространство `layout`](../layout.md#пространство-layout)

`FixedArray` — структура блока `layout<T>`. `fill` выделяет одну область ровно нужного размера, записывает все
элементы, и длина больше не меняется.

## Построчный разбор

| Строки | Почему код написан так |
|---|---|
| 1–2 | Параметр `T` стоит на блоке; область `Items` — непрерывные элементы формы `T`. Блок `private`: поля пишет модуль. |
| 4 | Тип программы — именованная структура блока, без обёртки и `Self`. |
| 5 | `items` владеет областью и допускает `null`: пустой массив памяти не выделяет. Закон поля: число элементов области равно `count`. |
| 6 | `count` читает любой код. Все `count` элементов области заняты: `0 ..< count`. |
| 10 | Стратегия для `FixedArray<T>`; `Movable` нужен для `take` элемента. |
| 11–13 | `fill` — ворота. Предусловие: массив пуст. Структуры `layout` не имеют конструктора, поэтому наполнение — обычный метод над значением `FixedArray<Int>()`. |
| 14 | Нулевой размер оставляет `items == null`. |
| 15 | Область нужного размера берётся у менеджера памяти. Размер указан в условии результата. |
| 16–21 | `make(i)` строит значение до записи, запись в пустой элемент `fresh[i]` его инициализирует. Функция `make` не бросает исключений, поэтому между выделением и публикацией выхода нет. |
| 22–23 | Область и длина публикуются вместе: закон поля `items` верен на выходе. |
| 27–33 | `replace` снимает прежнее значение и записывает новое; право `mut`, потому что `take` элемента делает ссылки на него мёртвыми. |
| 35–45 | `release` — ворота уничтожения: снимает все `count` элементов, возвращает область через `mm.free(old as Pointer)`, оставляет `items` пустым и `count == 0`. |
| 48–54 | Чтение копирует элемент, поэтому требует `T: Copyable`. Индекс проверяет `requires`. |
| 56–63 | Использование. Перед выходом из области `a.release()` освобождает владеющее поле: компилятор отвергает выход со структурой, у которой оно не пусто. |

## Свойства

Пустой массив — `items == null`, `count == 0`. Индексирование, чтение и замена имеют сложность `O(1)`, наполнение — `O(size)`.

Для `replace` и `release` действует [общее правило безотказного окна](README.md#общее-правило-применимости).
