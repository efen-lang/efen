# Массив из блоков

[К примерам](README.md) · [Исходник](chunked-array.efen) ·
[Основная модель](../addresses.md)

Значения `Target` лежат в блоках `Items.Area`; структуры с корневыми указателями
и размерами блоков лежат в каталоге `Chunks.Area`. Оба вида `Area` являются
чистыми указателями.

| 7–9 | `Chunks` содержит ровно записи инициализированного префикса каталога. |
| 11–13 | `Item` физически встраивает `Target`. |
| 15–16 | `Chunk` явно хранит корневой указатель блока; `Area` не хранит служебных данных. |
| 18–20 | Ёмкость блока записана отдельным числом и равна `CHUNK_SIZE`. |
| 22–25 | Длина блока не превышает ёмкость; строка 25 закрывает `Chunk`. |
| 27–32 | `Self` хранит допускающий `null` корневой указатель каталога и отдельно его ёмкость. |

| 134–138 | Выбирается последний блок по прежней длине. |
| 139–143 | Новый встроенный `Target` переносится в первое свободное место блока. |
| 144–146 | Сначала обновляется длина блока, затем общая длина. |
| 148–151 | `insert` проверяет позицию. |
| 153–156 | Будущая длина определяет нужное число блоков; память готовится заранее. |
| 158–164 | Сохраняется последний блок, а суффикс переносится справа налево. |
| 166–171 | В освободившемся месте создаётся новый `Item`. |

## Закон общего префикса

Для каждого блока с индексом `i`:

```text
chunk[i].length =
    min(CHUNK_SIZE, max(0, self.length - i * CHUNK_SIZE))
```

Все элементы `Items` находятся ровно в диапазонах
`chunk.root[0..<chunk.length]`. Закон нормативен, хотя синтаксис
квантора по блокам ещё не определён.

## Ошибки и очистка

`growDirectory` вызывается до выделения нового блока. Если рост завершается
ошибкой, нового блока ещё нет. Если завершается ошибкой `Items.allocateArea`,
выросшая ёмкость каталога может сохраниться, но логическая последовательность не меняется.
`Chunks.initialize` и следующие записи служебных полей после успешной подготовки
безотказны и не вызывают код, способный обратиться к изменяемой структуре.

При уничтожении каждого `Chunk` вызывается:

```efen
Items.free(
    root: take chunk.root,
    capacity: chunk.capacity,
    initializedCount: chunk.length
)
```

Затем `Chunks.free` получает корневой указатель каталога, `directoryCapacity` и
`directoryLength`. Рост каталога переносит только структуры `Chunk`; выделенные
области `Target` остаются на месте.

Индексирование имеет сложность `O(1)`, `append` — амортизированную `O(1)`,
`insert` и `remove` — `O(length - index)`.

Для сдвигов, публикации блока и очистки действует
[общее правило безотказного окна](README.md#общее-правило-применимости).
