# Проверочные структуры для `layout`

Пять структур данных, написанных по [описанию layout](../../layout-reference.md) и прогнанных через FLOW Amber
(`amber_flow_corpus_tests`, обычное чтение, amber main на 2026-11-08). Каждая содержит правильные функции и одну
намеренную ошибку с ожидаемой находкой (`//~`). Файлы служат набором
для проверки модели, а не нормативным синтаксисом. `layout` и функции в них написаны без модификатора, то есть
функции относятся к коду `layout`, и строк [схемы владения](../../layout-reference.md#схема-владения) (`own S`, `lend`) им не нужно:
владение `own Nodes.Item` переходит между функциями внутри `layout`.

| Файл | Структура | Результат на 2026-11-08 |
|---|---|---|
| `1_object_pool.efn` | область слотов, цепочка свободных, граница | тип `own block.cells.Item` не понят (взят `own Pointer`, как в mm); возврат слота `block.cells[k] = take cell` отклонён |
| `2_linked_list.efn` | список над `set area`, узел владеет следующим | результат `own Nodes.Item?` отклонён: `pop` не написать |
| `3_ring_buffer.efn` | область значений, голова и счёт | лишняя `flow.field-lent` при чтении слота; выход индекса за область не найден |
| `4_hash_map.efn` | область корзин, множество записей | слот области не владеет (по спецификации); запись `own` в поле-имя без находки; инвариант «запись в своей корзине» выброшен |
| `5_tree.efn` | дерево с именем родителя | результат `own Nodes.Item?` отклонён |

Сделать так, чтобы все пять ложились и находили свою ошибку, — задача модели `layout` и FLOW.
