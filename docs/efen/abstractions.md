# Программируемые языковые абстракции

В Efen программист может задавать не только данные и методы типа, но и правила,
по которым компилятор строит его реализацию. Например, представление типа
определяет хранение полей и операции с памятью, а аспект может добавлять
служебные поля и реализацию требований контракта.

```efen
class MyClass {
    var myProperty: Int = 0

    fn myMethod {
        print("Hello, Efen!")
    }
}
```

В исходном коде это класс с полем и методом:

```efen
let obj = MyClass()
obj.myProperty = 42
obj.myMethod()
```

Способ хранения поля и вызова метода относится к реализации класса.
Например, данные могут храниться непосредственно в полях или в другом
представлении, предоставленном типом. При этом сохраняются правила
исходной программы: типы полей, допустимые операции, владение и время жизни.
Выбор реализации не даёт права незаметно менять их смысл.

Правила формирования и поведения кода задают [контракты](contracts.md).
[Аспекты](aspects/README.md) участвуют в построении реализации,
[представления](representations.md) задают хранение данных,
а [стратегии](strategies.md) предоставляют поведение для выбранных типов.
Эти возможности составляют проект языка; их наличие в документации само
по себе не подтверждает реализацию компилятором.
