# Управляемые языковые абстракции

Управляемая языковая абстракция (Efen) - это элемент языка программирования, поведение которого
может быть полностью определено программистом как на этапе компиляции, так и на этапе выполнения.

Например, абстракция:
```efen
class MyClass {
    var myProperty: Int = 0

    fn myMethod() {
        print("Hello, Efen!")
    }
}
```

Может быть компилирована в структуру данных с полем `myProperty` и виртуальной таблицей методов, содержащей `myMethod`.
Или может быть компилирована в структуру данных с map ключ-значение для хранения свойств и статическим методом `myMethod`.

Иначе говоря поведение класса может быть определено программистом, а код ниже будет работать одинаково независимо от того,
как именно реализована абстракция `MyClass`:
```efen
let obj = MyClass()
obj.myProperty = 42
obj.myMethod() // Выведет "Hello, Efen!"
```
