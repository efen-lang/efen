# Runtime языка Efen

[Документация](../README.md) · [Контракты](../contracts.md) · [Память](../memory/README.md)

Runtime языка Efen — особая группа готовых контрактов, функций и типов,
доступная в языке всегда. Она задаёт общие операции над значениями и требования
к среде выполнения: от копирования и уничтожения до запуска программы,
исключений и системных вызовов.

Объявления языка находятся в `lang::` и поставляются с компилятором.
Они задают требования; исполняемые реализации предоставляет runtime,
стандартная библиотека или выбранный при сборке пакет. Компилятор знает,
с какими объявлениями связаны операторы и служебные вызовы.

## Доступность и реализация

Доступность объявления не означает, что любая операция допустима для любого
типа. `copy x` требует соответствия `Copyable`, а использование кучи —
подключённого аллокатора. Программа без кучи сохраняет обязательные объявления
языка и использует ту часть runtime, которая не выделяет память.

Runtime обязателен для программы; std подключается по умолчанию, но от неё можно
отказаться. Файлы, сеть, коллекции std и `print` описываются как возможности
библиотеки. Конкретные платформенные реализации и способы их замены указаны
в [перечне требований компилятора](lang-roles.md).

Общие механизмы `contract`, `conforms`, `implementation` и `allow implementations`
описаны в [статье о контрактах](../contracts.md). Правила памяти и `layout` —
в [разделе памяти](../memory/README.md), модели поведения — в [отдельной статье](../models.md).

[Прежние наброски низкоуровневого API](low-level-api.md) сохранены отдельно:
они не определяют обязательный состав runtime языка.
