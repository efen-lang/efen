# Поддержка объектов

[Runtime языка Efen](README.md) · [Встроенные контракты](built-in-contracts.md)

Контракт задаёт требования к операциям; хранимые поля объекта он не объявляет (поля `layout` контракта —
[модель поведения](../models.md#модели-контрактов-и-интерфейсов): в байтах их нет). Поле, которое нужно его
функциям, в тип добавляет аспект — [реализация извне](../contracts.md#реализация-извне): интерфейс не владеет памятью полей
([интерфейсы](../interfaces.md)). Например, класс со счётчиком пишет пустой контракт `ArcClass`, а поле `refCount` и
функции над ним даёт аспект из среды выполнения:

```efen
contract ArcClass {             // пишет класс: conforms ArcClass
    allow implementations from runtime, std
}

contract ArcOperations {        // реализует аспект; вызовы расставляет компилятор
    mut fn retain
    mut fn release
}

@default
aspect ArcCounter {
    implements ArcClass
    conforms ClassDefinitionHandler, ArcOperations

    private var refCount: UInt
}
```

Требований у `ArcClass` нет, поэтому класс ему соответствует без своих методов. `retain` и `release` (контракт
`ArcOperations`) даёт аспект, а вызовы расставляет компилятор; программа их не пишет и не вызывает. Соответствие
`Cloneable` классу тоже даёт аспект: `clone x` увеличивает счётчик ([подсчёт ссылок](../memory.md#подсчет-ссылок)).

## Служебные вызовы и построение класса

Методы `ArcOperations` вызывает только компилятор. Эти вызовы не добавляют
эффекта функциям программы. Аспект участвует в построении класса как
`ClassDefinitionHandler` один раз, у корня иерархии
([план построения](../aspects/compile-time/class.md#план-построения)).

Корень открытой иерархии объявляет `conforms OpenClass`. Описатель класса,
необходимый для переопределений, интерфейсных таблиц наследников и `catch`
по классу, предоставляет аспект `ClassDescriptor` по правилам
[реализации извне](../contracts.md#реализация-извне).
