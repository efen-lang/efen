# Видимость определений между пакетами и модулями

Видимость определений — важная часть организации кода в `Efen`.  
Она определяет, какие функции, классы, переменные и другие сущности доступны в различных частях программы.

## Уровни видимости

Видимость задают два уровня: модуль (`public module`, `private module`) и само определение (`public`,
`internal`, `private`, у членов классов ещё `protected` и `family`). Пространство имён своей видимости не имеет:
это только приставка к именам пакетов (решение Edmond от 2026-10-30, Q61).

## Базовые теги видимости

`Efen` использует три базовых тега для любых объявлений:

| Тег         | Описание                                            |
|-------------|-----------------------------------------------------|
| `public`    | Определение доступно из любого пакета.              |
| `internal`  | Определение доступно только внутри текущего пакета. |
| `private`   | Определение доступно только внутри текущего модуля. |

`internal` является значением по умолчанию и может применяться на любом уровне.

У членов классов дополнительно доступен `protected`: код объявляющего класса и
его наследников может обратиться к члену независимо от пакета. По умолчанию
`private`- и `protected`-член читается или изменяется только через `self`.

Для `private` множество допущенного кода остаётся текущим модулем, как указано
в таблице. Receiver-правило проверяется независимо от этой видимости.

Независимый модификатор `family` расширяет множество допустимых получателей до
любого экземпляра объявляющего класса или его наследника:

```efen
class Account {
    private var localSecret: Int
    private family var sharedSecret: Int
    protected var state: State
    protected family var familyState: State
}
```

`family` не расширяет множество кода, которому виден член. Он отвечает только
на вопрос, через какой объект уже допущенный код может обратиться к члену.
Поэтому `private family` остаётся private, а `protected family` — protected.

## Правила по умолчанию

1. Определение без тега — `internal`: видно всем модулям своего пакета и не видно другим пакетам.
2. Модуль без объявления — внутренний: другим пакетам из него не видно ничего.
3. Другим пакетам видны только определения с тегом `public` в модуле, объявленном `public module`. Остальные
   определения такого модуля остаются `internal` или `private`.
4. `private module` ограничивает все определения модуля этим модулем; `public` в нём — ошибка.

## Правила вычисления видимости

Видимость определения — самое строгое из правила модуля и тега определения:

| Модуль | Тег определения | Кому видно |
|---|---|---|
| `public module` | `public` | любому пакету |
| `public module` или без объявления | без тега или `internal` | модулям своего пакета |
| любой | `private` | только своему модулю |
| без объявления | `public` | ошибка: публичное определение в модуле, который не объявлен `public module` |
| `private module` | `public` или `internal` | ошибка: тег шире модуля |

Обращение к невидимому определению — ошибка в месте обращения. Сообщение называет определение, его видимость и
место объявления:

```efen
// model/tax/rates.efen
private fn round(x: Int) -> Int { ... }

// model/invoice.efen
use tax::rates

fn total -> Int {
    return round(10)     // ошибка: `round` объявлена `private` в model/tax/rates.efen:2
}
```

## Атрибуты пакета

`Efen` поддерживает механизм атрибутов, задающих поведение и уровень доступа элементов.

```efen
attributes {
    api: visibility(public), fastcall, dllexport
    internalApi: visibility(internal)
    ffi: abi(c), dllimport
}
```

Атрибуты пакета объявляются в корневом файле пакета — `lib.efen` библиотеки или `main.efen` программы (Edmond
2026-10-31) — и могут применяться к любым сущностям пакета:

```efen
api fn myApiFunction {
    // доступно в модулях и пакетах, указанных в атрибуте видимости
}
```
