# Типы и данные

[Документация](../README.md) · [Словарь](../glossary.md) · [Владение и память](../memory/README.md)

Этот раздел описывает типы Efen: от объявления имени и формы значения до
владения, состояний и generic-параметров. Сначала прочитайте основы, затем —
только нужную форму данных или ограничение.

## Базовые типы данных

| Тип | Назначение | Пример значения |
|---|---|---|
| `Bool` | Логическое значение | `true`, `false` |
| `Int` | Знаковое целое шириной с указатель целевой платформы | `42`, `-10` |
| `UInt` | Беззнаковое целое шириной с указатель целевой платформы | `42` |
| `Int8`, `Int16`, `Int32`, `Int64` | Знаковые целые фиксированной ширины: 8, 16, 32 и 64 бита | `-10` |
| `UInt8`, `UInt16`, `UInt32`, `UInt64` | Беззнаковые целые фиксированной ширины: 8, 16, 32 и 64 бита | `255` |
| `RawInt`, `RawUInt` и их варианты фиксированной ширины | Целые без проверок переполнения | `42` |
| `Float` | Число с плавающей точкой IEEE 754 binary64 | `3.14` |
| `Float32` | Число с плавающей точкой IEEE 754 binary32 | `3.14` |
| `Char` | Отдельный символ | `'A'`, `'Ж'` |
| `String` | Строка Unicode | `"Привет"` |

Тип можно указать явно или вывести из значения:

```efen
let enabled = true              // Bool
let count = 42                  // Int
let ratio = 0.5                 // Float
let name = "Efen"               // String
let marker: Char = 'E'
let byte: UInt8 = 255
let offset: Int32 = -10
let weight: Float32 = 0.5
```

`Int` и `UInt` имеют 32 бита на 32-разрядной цели и 64 бита на
64-разрядной. Для данных с фиксированным форматом выбирайте тип с явной
шириной. `Float` сохраняет формат binary64 на всех целях. Подробнее —
[ширина числовых типов](constants.md#ширина-числовых-типов).

Правила проверяемой арифметики и целых `RawInt`/`RawUInt` описаны в разделе
[целые без проверок](constants.md#целые-без-проверок). Для векторных вычислений
см. [SIMD](simd.md).

Отдельно используются `Void` — результат функции без возвращаемого значения
([функции](../functions.md)), и `Never` — тип выражения, которое не продолжает
обычное выполнение, например `throw`.

Отсутствие значения описывается типом `T?` и значением `null`
([optional](optional.md)). Строковые и символьные литералы подробнее описаны
в разделе [строки](strings.md).
