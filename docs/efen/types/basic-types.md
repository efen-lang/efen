# Базовые типы данных

[Типы и данные](README.md) · [Константы и числовые операции](constants.md) · [Строки](strings.md)

Для чисел, логических значений и текста в Efen используются `Int`, `Float`,
`Bool`, `Char` и `String`. Когда важны диапазон числа, точность вычислений
или поведение при переполнении, можно выбрать более конкретный тип.

Эта статья описывает типы и правила их использования в языке. Подробности
числовых операций приведены в [разделе о числах](constants.md#ширина-числовых-типов),
а работа с текстом — в [статье о строках](strings.md).

## Как указать тип

Тип записывается после имени через двоеточие. Если тип понятен из начального
значения, его можно опустить:

```efen
let count: Int = 42
let enabled: Bool = true

let retries = 3          // Int
let ratio = 0.5          // Float
let name = "Efen"        // String
let marker: Char = 'E'
```

Тип литерала может зависеть от того, где он используется. Например, в
объявлении `let weight: Float32 = 0.5` литерал сразу получает тип `Float32`.

## Логические значения: `Bool`

У `Bool` два значения: `true` и `false`. Этот тип используется для условий
и результатов сравнения:

```efen
let count = 5
let hasItems: Bool = count > 0
let ready = true

if ready && hasItems {
    echo "Можно продолжать"
}
```

Оператор `!` отрицает условие, `&&` означает «и», а `||` — «или».
При смешении `&&` и `||` нужны скобки:

```efen
let allowEmpty = false

if ready && (hasItems || allowEmpty) {
    echo "Можно продолжать"
}
```

Правила вычисления условий описаны в [статье об операторах](../operators.md).

## Целые числа

### `Int` и `UInt`

`Int` хранит целые числа со знаком, включая отрицательные. `UInt` хранит
только неотрицательные целые числа. Оба типа имеют ту же разрядность, что
и указатель на целевой платформе:

| Платформа | `Int` | `UInt` |
|---|---|---|
| 32-разрядная | От −2³¹ до 2³¹ − 1 | От 0 до 2³² − 1 |
| 64-разрядная | От −2⁶³ до 2⁶³ − 1 | От 0 до 2⁶⁴ − 1 |

```efen
let offset: Int = -12
let size: UInt = 4096
```

Размеры коллекций обычно выражаются через `UInt`, а разности адресов —
через `Int`, если соответствующий API не требует другого типа.

### Типы фиксированной разрядности

Для форматов файлов, сетевых протоколов и других данных, у которых заранее
известен размер целого числа, используются типы с указанной разрядностью.
Их диапазон одинаков на всех платформах.

| Разрядность | Знаковый тип | Диапазон | Беззнаковый тип | Диапазон |
|---|---|---|---|---|
| 8 бит | `Int8` | От −128 до 127 | `UInt8` | От 0 до 255 |
| 16 бит | `Int16` | От −32 768 до 32 767 | `UInt16` | От 0 до 65 535 |
| 32 бита | `Int32` | От −2³¹ до 2³¹ − 1 | `UInt32` | От 0 до 2³² − 1 |
| 64 бита | `Int64` | От −2⁶³ до 2⁶³ − 1 | `UInt64` | От 0 до 2⁶⁴ − 1 |

```efen
let byte: UInt8 = 255
let temperature: Int16 = -30
let packetLength: UInt32 = 1024
```

Нижнюю и верхнюю границы можно получить как `Int32.min`, `Int32.max`
и аналогично для остальных целых типов.

### Переполнение и деление на ноль

Обычные целые типы проверяют результат арифметических операций. Если он
выходит за допустимый диапазон, возникает `OverflowError`. Деление на ноль
вызывает `DivisionByZeroError`. Эти правила действуют и в отладочной,
и в выпускной сборке.

Например, прибавление единицы к `UInt8.max` вызывает `OverflowError`.
Литерал, который заведомо не помещается в указанный тип, отклоняется при
компиляции:

```efen
let valid: UInt8 = 255
let invalid: UInt8 = 256       // ошибка компиляции
```

### Арифметика по модулю: `RawInt` и `RawUInt`

В хешах, контрольных суммах и некоторых генераторах случайных чисел
переполнение входит в алгоритм. Для таких вычислений существуют `RawInt`,
`RawUInt` и типы фиксированной разрядности: от `RawInt8` до `RawInt64`,
от `RawUInt8` до `RawUInt64`.

При сложении, вычитании и умножении сохраняются младшие биты результата.
Например, после прибавления единицы к `RawUInt8.max` получается ноль.
Это отдельные числовые типы со своими правилами операций.

```efen
var counter: RawUInt8 = 255
counter += 1                     // теперь counter == 0
```

Деление на ноль по-прежнему вызывает исключение. Смешивать обычный целый
тип и `Raw`-тип в арифметическом выражении нельзя: требуется явное
преобразование. Литералы также должны помещаться в свой тип:
`let value: RawUInt8 = 256` — ошибка компиляции.

Правила сдвигов, преобразований и знакового переполнения приведены
в разделе [«Целые без проверок»](constants.md#целые-без-проверок).

## Вещественные числа: `Float` и `Float32`

| Тип | Формат | Размер | Точность |
|---|---|---|---|
| `Float` | IEEE 754 binary64 | 64 бита | 53 значащих двоичных разряда |
| `Float32` | IEEE 754 binary32 | 32 бита | 24 значащих двоичных разряда |

`Float` — обычный тип вещественного литерала. Его формат одинаков
на 32- и 64-разрядных платформах. `Float32` позволяет хранить число
в меньшем объёме памяти, но имеет меньшую точность и диапазон.

```efen
let ratio = 0.5                 // Float
let weight: Float32 = 0.5
let distance: Float = 1.0e6
```

Многие десятичные дроби нельзя точно представить в двоичном формате.
Поэтому результат операции округляется до ближайшего представимого числа:
например, `0.1 + 0.2` даёт `0.30000000000000004` в `Float`.

### Бесконечность и NaN

Вещественные вычисления могут давать специальные значения: положительную
или отрицательную бесконечность и NaN — результат, не являющийся числом.
Такие результаты сами по себе не вызывают исключение:

```efen
let infinity = 1.0 / 0.0        // положительная бесконечность
let invalid = 0.0 / 0.0         // NaN
```

NaN не равен даже самому себе. Для его проверки используется `isNaN`.
Значения `-0.0` и `0.0` равны при обычном сравнении, хотя имеют разные биты.

Подробности округления, сравнения, преобразований и доступа к битовому
представлению описаны в разделе [«Вещественные числа»](constants.md#вещественные-числа).

## Числовые литералы и преобразования

Целое число можно записать в десятичной, шестнадцатеричной или двоичной системе.
Подчёркивание между цифрами облегчает чтение и не меняет значение:

```efen
let limit = 1_000
let mask = 0xFF
let flags = 0b1010
let fraction = 1_000.25
let small = 1.0e-9
```

Литерал с десятичным порядком, например `1e9`, является вещественным даже
без точки. Целый литерал там, где ожидается вещественный тип, — ошибка:

```efen
let valid: Float = 2.0
let invalid: Float = 2          // ошибка компиляции
```

Для преобразования уже существующего значения используется имя нужного типа:

```efen
let source: Int = 42
let small = UInt8(source)
let fraction = Float(source)
let truncated = Int(2.9)        // 2: дробная часть отброшена
```

Преобразование в обычный целый тип проверяет диапазон. Например,
`UInt8(source)` вызывает `OverflowError`, если `source` отрицателен или
больше 255. При преобразовании из вещественного числа дробная часть сначала
отбрасывается, затем проверяется диапазон; NaN и бесконечность вызывают
`OverflowError`.

Правила контекстного выбора типа и шестнадцатеричных вещественных литералов
описаны в разделе [«Числовые литералы»](constants.md#числовые-литералы).

## Символы и строки: `Char` и `String`

Для символьного литерала используются одинарные кавычки, для строкового — двойные:

```efen
let marker: Char = 'Ж'
let message: String = "Привет, мир!"
let empty: String = ""
```

`String` хранит текст Unicode и по умолчанию использует UTF-8. Число байтов,
кодовых точек Unicode и видимых символов может различаться. Например,
буква с комбинируемым ударением или составной эмодзи может содержать
несколько кодовых точек.

Для этих величин предусмотрены разные операции: `byteLength()` считает байты
UTF-8, `length()` — кодовые точки, `graphemeLength()` — графемные кластеры.

В строку можно подставить значение выражения через `${...}`:

```efen
let count = 3
let message = "Найдено элементов: ${count}"
```

Экранирование, многострочные литералы, поиск и обработка текста описаны
в [статье о строках](strings.md).

## Отсутствие значения: `T?` и `null`

Если значение может отсутствовать, используется опциональный тип: `Int?`,
`String?` или, в общем виде, `T?`. Значение `null` обозначает отсутствие
значения этого типа:

```efen
var count: Int? = null
count = 42
```

`null` — не число `0` и не нулевой указатель. Его представление в памяти
задаётся в типе: это может быть специальное число, нулевой указатель или
отдельный признак отсутствия значения.

Опциональный тип позволяет отличить отсутствие числа от нуля, а отсутствие строки —
от пустой строки. Перед обращением к содержимому нужно обработать случай
отсутствия значения. Способы проверки и извлечения приведены
в [статье об опциональных типах](optional.md).

## `Void` и `Never`: как завершается вычисление

`Void` используется для функции, которая не возвращает полезного значения.
Если тип результата функции не указан, её результат — `Void`:

```efen
fn greet {
    echo "Привет!"
}
```

Правила возвращаемых значений описаны в [статье о функциях](../functions.md).

`Never` обозначает тип выражения, после которого обычное выполнение
не продолжается, например `throw`. Различие связано с потоком выполнения:
функция с результатом `Void` может завершиться и вернуть управление вызывающему
коду; выражение типа `Never` не даёт обычного результата.

## Как выбрать тип

| Задача | Тип |
|---|---|
| Условие, признак, результат сравнения | `Bool` |
| Обычные целочисленные вычисления | `Int` |
| Неотрицательное целое, например размер в API | `UInt` |
| Целое число с заданным диапазоном и размером | `Int8`…`Int64`, `UInt8`…`UInt64` |
| Целочисленный алгоритм с арифметикой по модулю | `RawInt`, `RawUInt` или вариант фиксированной разрядности |
| Обычные вещественные вычисления | `Float` |
| Вещественные данные, для которых достаточно binary32 | `Float32` |
| Символьный литерал | `Char` |
| Текст | `String` |
| Значение, которое может отсутствовать | `T?` |

Типы для связи с библиотеками C рассматриваются в [отдельной статье](../foreign.md),
а векторные вычисления — в [статье о SIMD](simd.md). Предложенные там дополнительные
числовые типы нужно отличать от утверждённых: статус указан в соответствующих документах.
