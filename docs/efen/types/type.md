# Алиасы типов

Алиасы типов позволяют создавать новые имена для существующих типов, что может улучшить читаемость и понимание кода.

## Синтаксис

```efen
type NewTypeName = ExistingType
type StringMap = [String: Int]
```

Алиасы не создают новые типы, а лишь предоставляют альтернативные имена для уже существующих.
Алиас действет в текущем scope видимости, и может быть определён на уровне модуля, функции или блока кода.

```efen
module

type UserID = Int
type UserName = String

```

## Структуры данных

Время жизни own-свойств структуры данных считается равным времени жизни самой структуры.

## Циклические ссылки

С точки зрения `Efen` важно не то, является ли ссылка циклической, а то, какой цели она служит.
Для иерархических структур данных циклические ссылки обычно отражают отношение от родителя к ребёнку.
В этом случае время жизни родителя должно быть больше времени жизни ребёнка.

Пример:

```efen
struct Node {
    children: NodeList
    parent: Node anchored
}
```

Специальный атрибут `anchored` указывает, что `parent` ссылка живёт как минимум столько же, сколько и `Node`, 
или больше.

Если же это не так, тогда проверка own невозможна. Нужно использовать ссылочные типы.
