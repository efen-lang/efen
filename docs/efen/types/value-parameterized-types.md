# Типы с параметрами-значениями

[Типы](type.md) · [Параметры типов](../generics.md) · [Перечисления](enum.md) ·
[Размеченные объединения](variant.md)

Параметром обобщённого объявления в Efen может быть не только тип, но и
значение, известное при компиляции: элемент перечисления, число, строка
или логическое значение. Параметрами также могут быть источник (`origin`),
контракт, интерфейс, стратегия и другие сущности времени компиляции.

Это часть обычной модели обобщённых объявлений Efen: само объявление
и полный нормализованный список его аргументов определяют конкретный тип. Отдельная система типов
для этого механизма не вводится.

<a id="тип-индексированный-enum-значением"></a>

## Тип с параметром-перечислением

```efen
enum UserKind {
    root
    admin
    other
}

class User<Kind: UserKind> {
    let id: UserId
    let name: String
}
```

Объявление создаёт семейство конкретных типов:

```efen
User<root>
User<admin>
User<other>
```

Это разные типы, даже если генератор кода выбрал для них одинаковое
представление в памяти. Между ними нет неявного преобразования.

Функция может принять только определённую категорию:

```efen
fn changeSystemConfiguration(user: User<root>) {
    // Доступ разрешён только User<root>.
}
```

Несколько категорий выражаются обычным структурным объединением:

```efen
fn manageUsers(user: User<root> | User<admin>) {
    // тело не важно для примера
}
```

Общий код объявляет тот же параметр:

```efen
fn displayProfile<Kind: UserKind>(user: User<Kind>) {

    // тело не важно для примера
}
```

В конкретном экземпляре типа значение `Kind` известно при компиляции.
Его можно использовать в условиях параметров, `invariants`, `requires`
и `#if`, при выборе представления в памяти и при генерации членов.

<a id="other-не-является-скрытым-wildcard"></a>

## `other` — обычный элемент перечисления

`other` — обычное значение `UserKind`, а не автоматическое дополнение множества.
Операция, которая читает более подробную роль времени выполнения, сама отображает `root` и
`admin` в специальные типы, а остальные значения — в `User<other>`.

Если программе нужна исходная подробная роль, она хранится обычным полем
значения. Параметр обобщённого объявления выражает только статически значимую категорию.

<a id="граница-runtime"></a>

## Когда категория известна только при выполнении

Значение времени выполнения нельзя непосредственно использовать как аргумент обобщённого объявления:

```efen
let kind = readUserKind()
// User<kind> — ошибка: kind не является compile-time значением.
```

Когда категория становится известна только во время выполнения, проверяющая
операция возвращает закрытый `variant`:

```efen
variant ClassifiedUser {
    root { let value: User<root> }
    admin { let value: User<admin> }
    other { let value: User<other> }
}
```

После `match` каждая ветка получает соответствующий конкретный тип. Метка активного случая
принадлежит `ClassifiedUser`; отдельный флаг внутри уже известного
`User<root>` не требуется.

Параметр обобщённого объявления сам по себе не аутентифицирует пользователя. Граница, создающая
специальный тип, обязана проверить доверенный источник, а владелец типа —
ограничить видимость конструкторов и фабричных функций так, чтобы внешний код не мог
обойти проверку. После такой границы наличие `User<root>` означает, что проверка
уже выполнена.

## Числовые и другие значения

Тот же механизм применим к числам и другим значениям времени компиляции:

```efen
class Matrix {
    generic Rows: Int { Rows > 0 }
    generic Columns: Int { Columns > 0 }
}
```

`Matrix<3, 4>` и `Matrix<4, 3>` являются разными конкретными типами. Выражение
аргумента обобщённого объявления сначала вычисляется и канонизируется, поэтому два выражения с
одинаковым результатом вычисления при компиляции обозначают один экземпляр типа.

Зависимость от конкретного объекта времени выполнения не возникает скрытно. Если свойство
значения времени выполнения нужно проверить, Efen использует условия, `refine()`, состояния типов, источники доступа
или доказательства компилятора. Значение переменной времени выполнения
не становится скрытой частью идентичности типа.

## Изменение категории

Аргумент обобщённого объявления является частью идентичности типа и не изменяется присваиванием
поля. Операция повышения или понижения категории проверяет свои условия и
возвращает значение другого конкретного типа:

```text
User<other> -> User<admin>
User<admin> -> User<root>
```

Передача владения, сохранение прежнего значения и возможные исключения
подчиняются обычной сигнатуре этой операции. Компилятор не меняет незаметно типы уже существующих псевдонимов значения.

## Идентичность и HIR

Ключ конкретного экземпляра обобщённого объявления содержит:

1. идентификатор обобщённого объявления;
2. упорядоченные канонические аргументы;
3. для аргумента-значения — его тип времени компиляции и `HirComptimeValueId`;
4. стратегии, выбранные для ограничений обобщённой сигнатуры
   ([тело обобщённого объявления](../strategies.md#тело-обобщённого-объявления));
   пакет, сделавший выбор, в ключ не входит.

Для `User<root>` аргумент-перечисление сохраняет идентичность `UserKind.root`,
а не только числовую метку, выбранную генератором кода. Межмодульный ключ обязан
быть устойчивым и типизированным.

Мономорфизация (создание специализированного кода) и стирание параметров
типов — способы реализации обобщённого кода. Они не объединяют разные
с точки зрения программы типы и не меняют их идентичность. Если значение
параметра нужно при выполнении, компилятор включает необходимые данные
в скомпилированную программу. Возникающие требования к контекстам
и возможные исключения остаются видимыми в сводке.

## Диагностика

На этапе анализа исходного кода отклоняются:

- выражение времени выполнения в позиции аргумента времени компиляции;
- аргумент неподходящего типа времени компиляции;
- ложное ограничение параметра, строка `invariants` или `requires` про параметры;
- неявное преобразование между разными экземплярами типа;
- обращение к недоступному конструктору или фабричной функции специальной категории;
- использование экземпляра обобщённого объявления без канонического межмодульного ключа.
